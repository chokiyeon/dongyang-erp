# 차량비·고지서 지급 확인

## 계산서나 매입 청구가 있는 경우

1. 매입 원본에서 거래처·합계금액·공사/본사 구분과 증빙 확인을 완료한다.
2. 차량비를 회사 부담으로 등록하고 같은 금액·공사 구분의 매입에 연결한다. 현재는 차량비 1건과 매입 1건 연결이다.
3. 지급은 매입 원본의 은행 연결에서 반영한다. 차량 화면에서 별도 납부액이나 출금을 추가하지 않는다.
4. 차량 화면에는 미지급·일부 지급·지급 완료가 표시된다. 지급 연결을 취소하면 남은 금액도 다시 표시된다.

차량 총원가 배부가 이미 있다면 매입에 연결하기 전에 기존 배부를 취소해 중복 원가를 정리한다. 연결한 매입의 금액/공사 구분을 바꾸거나 매입을 취소하려면 차량 연결부터 해제한다.

## 고지서만 있는 과태료·자동차세 등

### 예산안에 실제 지급을 반영한 경우

차량 비용 수정 화면의 ‘매입 없는 고지서 은행 대조’에서 금액·공사가 같은 완료 실적을 선택한다. 분할 지급도 실제 은행 지급 합계가 고지서 금액과 같으면 대조할 수 있다. 수기 실적·차액 완료·다른 원본에 쓴 지급은 대조할 수 없다.

### 아직 실제 지급을 반영하지 않은 경우

‘예산안에 아직 반영하지 않은 출금 직접 찾기’를 열고 고지서 발생일 이후 같은 금액의 실제 회사 출금을 선택한다. 먼저 기존 지급 예정/실적에 같은 건이 없는지 조회하고 확인한다. 기존 지급 예정이 있다면 그 예정에서 지급을 반영한 뒤 대조한다.

이 작업은 선택한 원래 출금을 예산안 완료 실적에 한 번 기록한다. 은행 출금액·잔액을 변경하거나 새 은행 출금·미래 지급 예정·공사 원가를 만들지 않는다. 저장 요청을 다시 보내도 같은 지급 실적을 중복 생성하지 않는다. 이미 매입/예산안에 반영한 출금은 새로 반영할 수 없다.

## 대조 해제와 지급 취소

대조 해제는 차량비와 지급 실적의 관계만 해제한다. 실제 은행 출금과 예산안 지급 기록은 보존한다. 지급 자체를 잘못 반영했다면 차량의 대조를 해제한 뒤 입출금 예정·실적에서 해당 지급을 취소한다. 마감한 지급일의 실적을 바꾸려면 해당 마감부터 재개방한다.

이전 달 비용을 다음 열린 달에 정상 납부할 수 있다. 이때 비용 발생일/금액을 바꾸지 않으며, 대조는 실제 지급일의 마감 여부를 검사한다.

## 원가와 세무

은행 지급 대조는 비용의 공사 배부나 세무 인정 여부를 확정하지 않는다. 매입 연결 비용은 매입 원가를 사용한다. 그 외 회사 부담 차량비는 ‘총원가 확인·공사 배부’에서 근거를 검토한다. 과태료·벌금의 관리 원가와 세무상 인정 비용은 다를 수 있으므로 회계사무소의 세무조정을 별도로 반영한다.

월말 점검은 부담 주체/납부 확인 누락과 회사 차량비 원가 배부 누락을 표시한다. 확인된 미납은 미확인과 구분한다. 이 기능은 은행 송금이나 세무 신고를 실행하지 않는다.
