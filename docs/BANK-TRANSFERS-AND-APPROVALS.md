# 회사 통장 간 이체·송금 검토본

## 통장 간 이체

자금 관리 → 회사 통장 간 이체에서 기간과 출금 거래를 선택하고, 다른 자사 계좌의 같은 금액 입금을 확인합니다. 6개 은행의 등록 계좌를 구분합니다. 거래일이 다르면 날짜 차이를 원본과 확인해야 합니다. 금액 차이·수수료를 임의로 맞추지 않습니다.

연결은 은행 원본 금액·날짜·잔액을 보존하고 양쪽 거래를 보통예금 1010·자사 이체로 표시합니다. 현장 배분·매입매출·예정 실적에 이미 연결된 거래는 먼저 해당 원본을 확인·해제해야 합니다. 한 거래를 두 개 이체 쌍에 중복 연결하지 못하며, 동시 처리도 버전과 활성 연결 고유 키로 보호합니다.

연결된 거래는 일반 분류·묶음 분류에서 바꾸지 못합니다. 연결 해제는 이전 계정·업무 종류·개별 이체 표시를 복원하고 은행 원본은 남깁니다. 이후 분류가 바뀌었으면 자동 복원을 중단합니다. 통합 장부에서 전체 실제 입출금과 자사 이체를 제외한 입출금을 구분합니다. 어느 합계도 매출·비용·이익을 뜻하지 않습니다.

## 송금 검토본·구두승인 기록

송금 준비표에서 이번 대상만 선택하고 최대 200건을 검토본으로 저장합니다. 금액·수취계좌·예금주·현장·원본을 당시 상태로 보관합니다. 서버가 같은 시점의 최신 지급 가능 자료를 다시 확인하며, 미확인·지급 상태 변경 등 보류 자료는 보관 대상으로 사용할 수 없습니다.

실제 대표자에게 구두승인을 전달받은 관리자가 회사 정보에 등록된 대표자·승인 전달일·전달 내용을 기록합니다. 미래 승인일이나 미등록 대표자를 거절합니다. 이는 승인자의 로그인·전자서명을 받은 전자결재가 아니라 기존 구두 업무의 전달 기록입니다. 공동대표의 결재 권한·정족수는 회사 규정을 별도로 적용합니다.

보관 후 금액·계좌·공사·원본·지급 상태가 바뀌면 승인 기록을 막고 새 검토본을 요구합니다. 이미 승인 기록이 있는 검토본도 변경 경고를 표시하며, 당시 계좌·금액을 덮어쓰지 않습니다. 승인 보류와 검토본 취소는 사유를 보존합니다. 인쇄·엑셀은 보관한 상태의 자료를 출력합니다.

저장·승인·취소가 은행 이체나 지급 완료/취소를 실행하지 않습니다. 실제 송금 직전 원본을 대조하고 송금 후 기존 은행 거래를 매입 또는 지출 예정에 연결하세요.
