# 기존 장부 검토와 이관 준비

기존 장부 가져오기는 원본을 수정하지 않는다. 후보와 확인 필요 행을 분리한 뒤 회사 계좌를 직접 연결하고 선택한 행만 저장한다. 이전 회계 구분은 참고로 보관하고 새 회계코드로 자동 확정하지 않는다. 원장 누계 잔액을 은행별 잔액으로 적용하지 않는다.

## 검토표 저장

파일과 시트를 선택한 뒤 ‘검토 결과 엑셀 저장’을 누른다. 검토표는 아래 3개 시트다.

- 검토 안내: 원본 시트·파일 SHA256·검토일·후보/확인 수와 후보 합계, 정리 방법
- 확인 필요 행: 원본 행·날짜·은행 표기·차입 입금/입금/출금 값·이전 구분·내용·확인 사유·메모
- 가져오기 후보 전체: 화면 페이지 수와 관계없이 전체 후보의 원본 행·일자·은행·금액·내용·이전 구분

확인 필요 행은 원본 행 번호로 찾아 사본에서 확인하고 정정한 파일을 다시 검토한다. 이 검토표 자체를 원본 장부로 다시 가져오는 방식이 아니다. 검토표 저장은 DB 가져오기나 행 선택을 실행하지 않는다.

## 자동으로 확정하지 않는 항목

날짜 누락/오류·미래 거래·은행 미기재/불명확·양방향 금액·차입/일반 입금 동시 기재·음수 금액·현금 거래 등을 은행 계좌에 임의 배정하지 않는다. 계산 결과가 없는 수식이나 엑셀 계산 오류도 빈칸/0원처럼 무시하지 않고 확인 대상으로 남긴다. 원본을 엑셀에서 재계산한 사본으로 다시 검토할 수 있다.

검토표에는 큰 금액과 이전 코드의 앞자리 0을 문자열로 보존한다. 원본 수식 문자열은 텍스트로 저장하며 실행 수식으로 만들지 않는다.

확인된 차입 입금 분리형과 거래처·내역·단일 입금 열 형식을 지원한다. 단일 입금 열에서는 차입 여부를 이전 코드로 추정하지 않는다. 병합된 빈 셀도 행별 확인 목록으로 분리한다. 다른 옛 시트는 자동 가져오기를 거절한다. 은행 식별 열이 없는 시트를 추정해서 현재 통장에 넣지 않는다. 실제 은행 파일과 장부를 함께 대조하고 작은 기간부터 시험 이관한다.
