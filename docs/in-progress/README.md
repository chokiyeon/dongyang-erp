# 재개할 작업: 기지급 전액취소·환급

사용자가 현장 근무자료를 급여대장에 적용하는 기능을 우선 요청하여, 기존 환급 백엔드 작업은 이 폴더에 초안으로 보존했다. 실행 코드에 연결하지 않았다.

- `paid-cancellation-backend.ts.txt`: 미검증 백엔드 초안. 전체/부분 환급 범위를 혼동하지 않는다.
- `paid-cancellation-hooks.patch`: 전액취소 정정과 원 지급 해제 보호 연결 초안.
- `20261103010000_paid_cancellation_refunds`는 이미 개발 DB에 적용된 추가 마이그레이션이다. `CashPlan.refundCancellation`, `TradeCancellation.refundPlanId/paymentBasis` 필드는 미래 확장을 위해 스키마에 유지한다. 이 상태로 환급 업무를 구현 완료했다고 표시하지 않는다.

활성화 전 필수: 환급 소유 예정의 다른 원본 승계/수정 차단, 실제 은행 거래에 한정한 부분/전액 환급 연결·취소, 원 지급 고정·정정, 송금 준비·회계 전달·기간별 집계, 동시 요청·원본 마감과 이후 월 환급, 상태/예정 일관성 검증. 초안을 단순 연결하여 서비스하지 않는다.
