# 전액취소 후 수정 재발급

양수 수정 세금계산서는 일반 새 청구로 무조건 가져오지 않는다. 원본 검토의 ‘재발급 이관 준비’에서 같은 달·같은 사업자의 전액취소 원본과 연결한다. 취소일 이전 작성일이나 이미 등록 정정한 취소, 다른 회사/구분/사업자 원본은 거절한다. 수정된 새 금액이 이전 금액과 달라도 실제 새 원본의 금액으로 등록한다. 원본 파일을 다시 읽어 금액을 검증하고 송금/은행 실적은 생성하지 않는다.

일반 양수 원본도 사용자가 재발급 관계를 명시해 연결할 수 있다. 수정 원본 중 기재 오류·음수·중복·충돌 등이 섞인 행은 해당 검토가 먼저 필요하다. 부분 증감액을 전액취소 후 재발급한 총액으로 임의 해석하지 않는다.

새 청구의 이관 원본은 전액취소 이력을 가리키며, 문서 상세·취소 상세·회계 전달본에서 관계를 확인한다. 활성 재발급 청구가 있으면 옛 청구 복원을 막는다. 재발급이 다시 취소되고 또 재발급되는 연쇄 이력도 확인해 살아 있는 후속 청구가 있으면 복원하지 않는다. 여러 세금계산서 원가/미지급을 중복 계산하지 않도록 원본·취소·새 청구를 구분한다.

현재 지원은 같은 달 미정산 전액취소와 그 재발급 연결이다. 부분 증감·기지급 환급·다른 달의 수정은 별도 미완료이며 지급/은행 기록을 지워 이 경로로 억지 처리하지 않는다. 실제 발행·취소나 회사 자료 자동 이관을 실행하지 않았다.
