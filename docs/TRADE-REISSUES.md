# 전액취소 후 수정 재발급

양수 수정 세금계산서는 일반 새 청구로 무조건 가져오지 않는다. 원본 검토의 ‘재발급 이관 준비’에서 같은 작성월 또는 이후 작성월·같은 사업자의 전액취소 원본과 연결한다. 취소 작성월보다 앞선 작성월이나 이미 등록 정정한 취소, 다른 회사/구분/사업자 원본은 거절한다. 수정된 새 금액이 이전 금액과 달라도 실제 새 원본의 금액으로 등록한다. 원본 파일을 다시 읽어 금액을 검증하고 송금/은행 실적은 생성하지 않는다.

일반 양수 원본도 사용자가 재발급 관계를 명시해 연결할 수 있다. 수정 원본 중 기재 오류·음수·중복·충돌 등이 섞인 행은 해당 검토가 먼저 필요하다. 부분 증감액을 전액취소 후 재발급한 총액으로 임의 해석하지 않는다.

새 청구의 이관 원본은 전액취소 이력을 가리키며, 문서 상세·취소 상세·회계 전달본에서 관계를 확인한다. 활성 재발급 청구가 있으면 옛 청구 복원을 막는다. 재발급이 다시 취소되고 또 재발급되는 연쇄 이력도 확인해 살아 있는 후속 청구가 있으면 복원하지 않는다. 여러 세금계산서 원가/미지급을 중복 계산하지 않도록 원본·취소·새 청구를 구분한다.

미정산 및 기지급 전액취소를 재발급에 연결할 수 있다. 다른 달 취소의 원 작성월·수정월 자료도 보존한다. 미회수 환급이 있어도 실제 새 계산서는 별도 청구로 기록하며, 새 청구에 과거 은행 지급을 복사하거나 금액을 자동 상계하지 않는다. 미회수 환급이 연결된 매입은 송금 준비표에서 보류한다. 실제 은행 환급을 모두 대조하면 이 보류를 해제하고, 환급 연결 오류를 정정하면 다시 보류한다. 활성 재발급을 정정한 뒤에는 옛 취소를 복원할 수 있지만 활성 후속 청구가 있는 동안은 복원하지 못한다. 기지급 부분 감액과 실제 상계 처리는 별도 미완료다. 실제 발행·취소나 회사 자료 자동 이관을 실행하지 않았다.

작성일자는 발급·처리 순서와 다를 수 있으므로 같은 달 기준으로 원본 관계를 확인하며 날짜 선후를 근거 없이 재작성하지 않는다. 발급·전송 원문은 원본에 보관한다.
