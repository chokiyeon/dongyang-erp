# 통장별 월말 잔액 대조

월초 잔액은 전월 말일 종료 잔액이다. 실제 은행 원본의 월초·월말 잔액을 입력해 등록 거래와 대조한다. 월초 + 입금 − 출금 = 장부 계산 잔액, 은행 월말 − 장부 계산 잔액 = 차이다. 통장별 대조에는 내부이체도 포함하며, 통합 손익·자금 유입/유출 합계의 내부이체 제외와 구분한다.

차이가 있으면 미확인 임시 저장은 가능하지만 대조 완료로 저장할 수 없다. 0원·음수·미입력은 구분한다. 마이너스통장의 실제 잔액은 음수이며 약정 한도를 잔액에 더하지 않는다. 월말이 지난 기간만 확인할 수 있다.

사용 중지 통장을 포함한 모든 회사 통장이 대조 완료되어야 월말 순잔액을 예산안 기준 잔액으로 반영한다. 기존 기준 잔액은 보존하고 새 차수로 저장한다. 대조 원본 기준과 저장 요청·변경 사유를 보관한다.

은행 거래가 추가·변경되면 대조 기준이 달라진다. 통장 버전과 은행 원본 지문을 확인하고, 이미 예산안 기준 잔액에 사용한 대조가 변경되면 예산안 계산을 보류한다. 다시 대조하고 기준 잔액을 반영해야 계산한다. 계좌별 잔액을 자동 추정하거나 미확인 통장을 제외해 합산하지 않는다.

월말 점검과 회계 전달본에 대조 상태·금액·원본 근거를 포함한다. 원본 데이터나 은행 잔액을 수정하는 기능이 아니다. 통장에 등록되지 않은 거래는 자동 검출할 수 없으므로 실제 은행 원본 대조가 필요하다.
