# 개발 진행 순서

사용자 지시: 경리업무를 먼저 마무리하고 이어서 공무업무를 개발한다. 경리와 공무는 같은 현장·거래처·증빙을 공유하며 중복 장부를 만들지 않는다.

## 경리 업무 마무리

- 기존 장부·예산안·상용직/일용직 급여 형식을 유지하며 미확인 원본, 지급 예정과 실적, 현장 배부를 연결한다.
- 월말 점검에서 누락·변경 대상을 찾고, 직원별 명세서 검토/저장, 송금 준비와 구두승인 기록, 회계 전달본 생성·변경 확인까지 연결한다.
- 잔여 구현·검증은 DELIVERY-CHECKLIST.md의 남은 범위와 함께 관리한다. 화면이 있다는 이유로 실제 자료 대조·세무 검증·운영 개통이 완료됐다고 표시하지 않는다.
- 실제 은행 양식·세무 신고 기준·노무 신고와 보험 회사 부담분은 검증 가능한 근거를 적용한다. 모르는 세율이나 금액을 추정해 확정 지급·원가로 저장하지 않는다.

## 공무 업무 후속 개발 초안

아래는 기존 요청을 연결하기 위한 초안이며 회사 고유 공무 절차가 확정됐다는 뜻은 아니다.

1. 현장별 계약·변경계약·착공/준공 일정과 제출 서류 관리
2. 공사 내역·실행예산·기성 청구 및 수금 일정 연결
3. 작업일보·투입 인력·자재 집계와 원본 증빙 연결
4. 준공·정산 서류, 미수금과 공사별 최종 손익 확인
5. 인수인계용 현장별 자료 묶음·출력

기존 공사·원가·자재·노무·미수 자료를 재사용한다. 법정 신고·제출을 자동 실행하지 않고 실제 회사 양식과 필요한 항목을 검증하며 확장한다.
