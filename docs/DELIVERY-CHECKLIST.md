## 전체 완료의 기준

- 남은 원본 연결·중복 방지와 기간 마감까지 구현하고 합성 자료로 업무 전체를 검증합니다.
- 사용자 확인이 필요한 계약·세무·원가 기준을 임의 확정하지 않습니다. 실지급액을 총 노무 원가나 신고 금액으로 바꾸지 않습니다.
- 실제 회사 자료는 기존 장부를 보존한 상태에서 작은 기간부터 대조하고 이관합니다.
- 서버 비용·실제 운영 개설은 별도 결정 사항입니다. 개발 환경의 기능 검증만으로 회사 사용 개통을 완료했다고 표시하지 않습니다.

## 시험판 마무리 검증

핵심 업무 화면을 개발 환경에서 연결했습니다. 실제 세무·보험 기준 자동 산정, 재고 결산 평가, 개인별 권한·원본 첨부/OCR, 은행별 대량 이체와 운영 서버는 전체 개통의 후속 범위입니다. 이 목록을 숨기고 전체 운영이 끝났다고 표시하지 않습니다.

화면 미리보기는 합성 자료의 실제 화면 촬영본이며 회사 사용 주소가 아닙니다. 사용자가 결정할 서버 비용·운영 계정과 실제 자료 대조가 완료돼야 회사에서 업무를 전환할 수 있습니다.
