# 환급 일정·잔액 화면 검증

2026-11-04 개발. 회사 PC/NAS 설치, 회사 실자료 이관, 실제 이체는 실행하지 않았다.

## 구현

- 활성 환급 계획의 날짜만 전용 화면에서 변경하고, 원 지급·환급액·통장 연결·방향·계좌를 유지한다.
- 한국 날짜의 변경일, 이전/새 예정일, 변경 당시 실제 환급/잔액, 사유를 FinanceChange에 보관한다. 기존 스키마를 사용해 새 마이그레이션은 없다.
- 완료/정정/마감/과거일/미확인/원본 불일치를 거부한다. 같은 요청의 재시도는 한 번만 보관하고 다른 동시 변경은 버전으로 차단한다.
- 변경 당시가 포함된 회계 전달본에 일정 변경 참고표를 넣는다. 이후 월에 바꾼 날짜는 이전 월의 전달본을 다시 계산할 때 되돌려 사용한다. 예를 들어 11월 변경이 10월 전달본 해시를 바꾸지 않는다.
- 송금 검토본 최신 기준에서 일정 변경을 감지하고, 자금 전망에는 남은 잔액만 새 날짜로 옮긴다.
- 환급 잔액 화면은 미완료 회수·지급액과 기한 경과액을 분리하고 필터·페이지·증빙/통장 연결 링크를 제공한다. 원본 불일치 자료는 합계에서 제외한다.

## 검증 항목

환급 원본 단위/DB 검사에는 기존 취소·부분 지급·부분 환급에 더해 일정 변경 실적/금액 보존, 변경 전후 송금 기준, 미래 월 전망, 기존 작성월 마감 상태에서 현재 일정 변경, 이전 월 전달본 해시, 동일/상이 동시 요청, 마감·과거일·완료 거부, 여러 달 변경의 날짜 복원을 포함한다.

실제 브라우저에서는 전액/일부 지급 원본의 취소·환급 후 잔액 화면에서 금액/기한 경과를 확인하고, 날짜를 바꾼 뒤 날짜 필터와 송금 준비에서 빠지는지 확인한다. 원본 다운로드·다음 달 회계 ZIP·실적 해제·입력 정정 복원도 함께 검증한다.
