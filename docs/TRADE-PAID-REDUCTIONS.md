# 기지급 부분 감액과 별도 환급

매입매출 엑셀 원본 검토에서 음수 행의 ‘기지급 부분 감액 검토’ 또는 ‘다른 달 기지급 부분 감액 검토’를 선택한다. 원본 사업자·구분·승인번호·공급가액·세액과 실제 은행 지급을 대조한다. 수정 전후 금액과 원본 파일, 지급 연결 식별자는 보존한다. 회사 실자료를 자동 이관하지 않으며 실제 송금도 실행하지 않는다.

## 잔액과 환급

110만 원 청구 중 40만 원을 지급한 뒤 22만 원 감액하면 청구는 88만 원, 원 지급은 40만 원, 남은 미지급은 48만 원이다. 별도 환급은 만들지 않는다.

110만 원을 이미 전액 지급했다면 같은 감액 후 청구는 88만 원, 원 지급 기록은 110만 원, 미지급은 0원, 별도 환급 예정은 22만 원이다. 홈·거래처/공사 미수미지급·공사 손익에서 초과 지급액을 다른 청구의 미지급액과 상계하지 않는다. 환급은 원화의 실제 은행 거래로만 일부/전액 대조하며 초과 연결·차액 임의 완료·다른 청구와 중복 연결을 막는다.

다시 감액하면 원 지급 대비 초과분의 증가액만 새 환급 예정으로 만든다. 선행 환급이 남거나 이미 환급됐어도 같은 돈을 재차 환급 예정으로 만들지 않는다. 감액 후 잔액 전액취소 시에도 선행 감액 환급을 별도 유지하고 나머지만 취소 환급으로 분리한다. 각 원본과 환급 일정·실적을 독립적으로 확인한다.

매출의 감액 환급은 송금 준비표에도 포함한다. 매입의 감액 환급은 ‘환급 잔액 현황’에서 돌려받을 돈으로 표시한다. 원 지급 기록은 바꾸지 않으며 실제 환급을 원 지급액에서 지우지 않는다. 이는 별도 은행 거래로 회수/반환한 금액이다.

## 작성월·정정·예산안

같은 달 감액은 원 작성월 순액에 반영한다. 다른 달 감액은 원 작성월 금액·당시 은행 연결·기존 예산안 식별자를 유지하고 수정 작성월에 음수 차액을 한 번 반영한다. 이후 환급이나 일정 변경이 이전 월 회계 전달본을 다시 쓰지 않는다. 환급 내역은 별도 참고표와 원본 ZIP에 포함하며 원가/세액에 재가산하지 않는다.

남은 환급의 예정일만 변경할 수 있고 실제 환급액·남은 환급액·변경일과 사유를 기록한다. 금액을 변경하거나 다른 원본이 환급 예정을 가져갈 수 없다. 원래 예산안은 감액 후 순액에 맞추며 기존 은행 실적은 보존한다.

입력 오류는 가장 최근 감액부터 정정한다. 실제 환급 연결이 있으면 이를 먼저 대조·해제해야 한다. 후속 지급이 있다면 그 지급을 먼저 확인하고, 기지급 감액을 등록할 당시의 원 지급 연결은 감액 정정 전에 해제하지 못한다. 감액을 정정해도 은행 거래 자체를 지우거나 실제 돈을 돌려보내지 않는다. 원본의 자재·차량·공사 원가 배부 연결은 아직 별도 정산 범위이며 이 경로로 우회하지 않는다.
