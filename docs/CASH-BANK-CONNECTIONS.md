# 입출금 예정과 은행 실적 연결

입출금 예정·실적에서 ‘상세·처리’를 열면 기존 수기 실적과 함께 ‘은행 거래로 실제 처리 반영’을 사용할 수 있다.

1. 은행 적요를 검색하고 예정과 같은 방향의 거래를 선택한다.
2. 이번에 반영할 금액과 사유를 입력한다. 실제 처리일은 은행 거래일을 사용한다.
3. 실제 처리 누계와 남은 예정액이 갱신된다. 필요하면 최종 정산 완료를 선택해 차액을 더 이상 예정으로 남기지 않는다.
4. 잘못 반영한 실적은 ‘최근 실제 처리 취소’에서 사유와 함께 취소한다. 수기 실적도 취소할 수 있다.

- 같은 실적을 수기와 은행 연결로 중복 등록하지 않는다. 하나의 은행 거래를 여러 예정으로 나누어 반영할 수 있지만 유효 은행 연결 실적의 합계는 은행 거래액을 넘을 수 없다.
- 은행 거래를 새로 만들거나 거래일·금액·잔액을 변경하지 않는다. 실제 처리 취소도 은행 이체를 취소하거나 환불하지 않는다.
- 가장 최근에 등록한 유효 실적부터 순서대로 취소한다. 취소 시 완료 상태를 해제하고 남은 예정액과 자금 전망을 다시 계산한다. 취소 사유와 원래 처리 내역은 보관한다.
- 자금 전망은 취소되지 않은 실적만 포함한다. 기준 잔액일 이전의 실적은 잔액에 이미 반영된 것으로 보고 다시 더하거나 빼지 않는다.
- 은행 연결 실적이 있는 거래를 회사 계좌 간 이체로 바꾸려면 실적을 먼저 취소한다. 개별·묶음 분류 및 묶음 되돌리기에 적용한다.
- 같은 은행 거래를 매입·매출 정산과 예정 실적 양쪽에서 연결할 수 있다. 채권·채무 정산과 자금계획이라는 다른 관점이며 금액을 서로 더하지 않는다.
- 매입·매출 청구를 등록했다고 입출금 예정이 자동으로 생기지는 않는다. 수동으로 등록한 일정과 청구를 자동 합산하지 않는다.

현재 은행 검색은 최근 100건 중 연결 가능 잔액이 있는 거래를 표시한다. 원하는 거래가 보이지 않으면 적요 검색을 사용한다. 회사 자금 전망은 등록된 예정·실적과 확인한 기준 잔액에 대한 전망이며 미등록 은행 거래까지 자동 반영한 전체 현금 잔액은 아니다.
