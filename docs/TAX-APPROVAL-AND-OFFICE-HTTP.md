# 전자 승인번호와 사내 접속 검증

매입·매출 등록의 전자 승인번호는 세금계산서에 선택 입력한다. 관리번호는 회사 내부 문서 식별자이며 전자 승인번호와 별개다. 국세청 조회나 진위 확인을 자동 수행하는 기능은 아니다.

같은 회사의 취소되지 않은 문서는 동일 승인번호를 사용할 수 없다. 공백·하이픈·전각 문자·영문 대소문자는 정규화해 비교한다. 동시에 저장해도 DB 고유 인덱스로 한 건만 허용한다. 잘못 등록한 문서를 취소한 뒤 재등록할 수 있으며 취소 문서의 번호와 변경 이력은 보존한다. 승인번호가 없는 과거 문서에는 임의 번호를 부여하지 않는다. 승인번호만으로 기존 과거 자료의 중복이 모두 탐지되는 것은 아니다.

승인번호는 목록 검색과 회계 전달본에 포함한다. 원가 배부 원본의 승인번호를 변경하면 다시 검토해야 한다. 기존 승인번호 미입력 문서의 원가 검토는 필드 추가만으로 무효화하지 않는다.

## 사내 HTTP

사내 IP의 HTTP 접속에서는 브라우저의 일부 Web Crypto API가 제공되지 않는다. 장부 가져오기 검증값은 같은 SHA256으로 대체 계산하고 첨부 요청번호는 안전한 getRandomValues 난수로 만든다. 배부 입력행 식별자는 화면 내부 순번으로 관리한다.

브라우저 검증에서는 crypto.subtle과 crypto.randomUUID를 제거한 상태로 장부 가져오기·증빙 첨부·공사 배부를 실행한다. 이는 호환성 모의 시험이며 회사 Windows, 실제 네트워크, NAS 접근 시험 완료를 뜻하지 않는다. 외부 인터넷 공개나 공유기 포트 개방을 수행하지 않는다.
