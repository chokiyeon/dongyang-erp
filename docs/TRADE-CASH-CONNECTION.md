# 매입·매출과 예산안 연결

매입·매출 상세 → 예산안 입출금 예정 연결에서 같은 금액·기한·방향의 기존 미처리 예정을 재사용하거나, 중복 예정이 없음을 확인하고 생성한다. 원본 확인과 지급기한이 필요하며 어음 지급은 어음대장으로 처리한다.

- 기존 매입·매출은 자동으로 변경하지 않는다. 사용자가 문서별로 연결한다.
- 원본 총액을 당초 예정액으로 보존하고 은행 연결을 실적으로 반영한다. 일부 지급/수금이면 잔액만 미래 예정에 남고 전액이면 완료된다.
- 이미 연결된 은행 실적도 예산안으로 승계한다. 다른 자금예정이 같은 은행 금액을 이미 사용했다면 전체 연결을 롤백하고 중복 해제를 안내한다.
- 은행 연결 해제 시 예산안 실적도 취소하고 남은 예정을 복원한다. 은행 원본 금액·잔액은 바꾸지 않는다.
- 연결된 예정의 처리·취소는 매입·매출 은행 연결 화면에서 수행한다. 별도 수기 처리로 중복 반영할 수 없다.
- 문서의 금액·기한 변경은 원본 검증과 버전 확인 뒤 연결된 예정에도 반영한다. 원본 확인/기한/계좌 송금 조건은 유지해야 한다.
- 은행 연결이 없는 상태에서만 예산안 연결을 해제할 수 있다. 과거 예정은 종료하고 이력은 보존한다.
- 문서 취소 시 미처리 예정도 종료한다. 실적이 있는 문서는 먼저 은행 연결을 해제해야 한다.
- 급여·어음·정기지급 또는 다른 문서가 사용하는 예정은 재사용할 수 없다. 정기 지급이 매입 문서를 원본으로 쓰는 경우에는 그 매입 문서의 예정 하나를 사용한다.

회계 전달본에 연결 자금예정 식별자를 보관한다. 월말 점검에서 미수·미지급 예산안 미연결을 표시한다. 매입·매출과 자금예정은 같은 경제 사건의 다른 관점이므로 잔액을 서로 더하지 않는다.
