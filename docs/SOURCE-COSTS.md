# 확인한 총원가의 공사 배부

공사 관리 → 총원가 확인·공사 배부에서 급여 지급 원본 또는 회사 부담 차량 비용을 선택합니다. 원본 관리액은 참고이며 총원가에 자동 복사하지 않습니다.

급여는 실지급액에 원천 공제·수당·회사 부담분 등을 검토한 총 노무원가를 확인합니다. 차량은 부가세·회사 부담·비용 귀속을 검토합니다. 같은 비용을 매입이나 기존 수기 발생원가에 중복 등록하지 않았는지 확인합니다. 운전자 부담·부담 미확인 차량비는 회사 원가 원본으로 선택할 수 없습니다.

확인 총원가, 실제 발생일, 본사 공통액과 현장별 배부액을 입력합니다. 현장 배부액+본사 공통액은 총원가와 정확히 같아야 합니다. 현장 중복과 타사 현장을 거절하며, 급여 발생일은 귀속월 안에서 지정합니다. 배부 근거·검토 사유를 보관합니다.

현장 배부는 원가 항목(급여=인건비, 차량=기타비)으로 한 번만 생성합니다. 다시 검토·배부하면 같은 연결 원가를 갱신하며 새 원가를 중복 추가하지 않습니다. 제외한 배부와 취소한 원가는 이력을 보존하고 손익에서 제외합니다. 본사 공통분을 임의로 현장에 나누지 않습니다.

출역·계약·급여 또는 차량 원본이 바뀌면 연결 원가를 미확인으로 바꾸고 해당 공사의 기존 손익 검토를 해제합니다. 재검토 전에는 이익 계산을 보류하며 현장 손익 화면에서 검토 확인만 눌러 우회할 수 없습니다. 원본 연결 원가는 수기 발생원가 화면에서 수정·취소하지 못하며 이 화면에서 처리해야 합니다.

확인되지 않은 세금·보험료나 회사 부담분을 임의 산정하지 않습니다. 자동 신고·재고 원가 평가·본사 전체 결산을 대신하지 않습니다. 기존 수기 인건비·차량비를 이 기능으로 옮길 때는 해당 수기 원가와 중복되지 않도록 원본을 대조해야 합니다.
