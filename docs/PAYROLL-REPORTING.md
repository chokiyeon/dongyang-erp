# 급여 신고자료·회사 부담분

실지급 급여와 신고금액을 분리한다. 월별 지급 확인을 저장한 직원에 대해 신고금액·신고일수·회사 부담 국민연금/건강/요양/고용/산재보험, 퇴직급여 원가·기타 원가를 입력한다. 미확인 항목을 0원으로 가정하지 않으며 해당 없는 항목도 명시적으로 0을 확인한다.

- 원본 고지서나 회계사무소 자료 확인 근거와 변경 사유를 남긴다. 법정 신고 금액이나 보험료를 프로그램이 임의로 결정하지 않는다.
- 총노무원가 검토액 = 확인된 공제 전 급여 + 회사 부담분이다. 직원에게 공제한 보험료·세금은 회사 부담분에 다시 더하지 않는다.
- 입력·정정만으로 실지급액이나 은행 거래를 수정하지 않는다. 신고금액은 세후 지급액으로 자동 복사하지 않는다.
- 급여·출역·계약 변경 후에는 신고자료 재검토를 표시한다. 신고자료를 수정하면 기존 총노무원가와 현장 배부를 재검토 상태로 바꾼다.
- 원가 배부 화면은 확인한 회사 부담분 합계를 제안하며 이 검토액과 다른 금액을 배부하려면 먼저 부담분 내역을 정정한다. 현장별 배부와 중복 비용 여부는 별도로 확인한다.
- 같은 저장 요청 재시도·동시 수정·다른 회사 직원·원 미만·금액 초과·월 일수 초과를 보호한다.
- 회계 전달본과 월말 점검에 신고금액·회사 부담분·검토 상태를 포함한다. 세무 신고용 전산 매체 자동 제출이나 관할기관 신고·납부는 실행하지 않는다.
