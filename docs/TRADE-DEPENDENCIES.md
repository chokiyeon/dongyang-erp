# 청구별 정산 연결 현황

매입·매출의 상세 화면에서 **정산 연결 현황**을 확인한다. 다른 장부에서 원가나 지급 내역을 다시 찾지 않도록 다음 참조를 모은다.

- 입금·지급 예정과 실제 은행 연결액
- 여러 공사 총원가 배부, 현장별 배부액, 본사 공통액과 재검토 여부
- 차량 번호·비용 관리번호와 해당 차량 비용 화면
- 정기 지급의 귀속월과 해당 월 준비 화면
- 자재 입고·반품·단가 조정의 구분별 건수/공급가액
- 원 작성월을 보호하는 마감 기간

참고액은 각 장부의 서로 다른 기준이므로 합산하지 않는다. 조회는 은행 금액·원가·배부 상태를 변경하지 않는다. 이미 배부했거나 차량/정기 지급에 연결된 청구의 취소·감액을 이 표의 확인만으로 허용하지 않는다. 기존 정산 검증을 유지한다. 마감 원본을 임의 해제하지 않는다.

자재 연결 원본 확인을 누르면 해당 청구의 입출고만 조회한다. 품목·장소 조회에도 청구 필터를 유지한다. 재고 잔량은 전체 입출고로 계산하고 화면에 그 기준을 표시한다. 취소 계산서도 원본을 조회하며 취소 원본의 차액을 추가 비용으로 표시하지 않는다. 다른 회사 또는 없는 원본의 필터는 조회할 수 없다.

DB 스키마 변경 없음. DB 합성 검사는 조회의 금액·버전 불변과 다른 회사 원본 비공개를 확인한다. 회사 실제 자료를 대조하거나 정산을 자동 실행하지 않았다.
