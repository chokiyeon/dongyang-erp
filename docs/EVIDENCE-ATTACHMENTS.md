# 증빙·원본 파일 보관

기준정보 → 증빙·원본 파일에서 공사·매입매출·직원·출역·급여·차량비·자재 입출고 원본을 선택해 첨부합니다. 업무 화면의 원본 파일·사진 첨부 링크로도 이동합니다. 회사 공통 자료는 별도로 보관합니다.

PDF, JPG/PNG, 엑셀(XLS/XLSX), 워드(DOC/DOCX), PPT/PPTX, HWP/HWPX를 파일당 10MB까지 보관합니다. 파일 이름·기본 형식·문서 압축 구조·크기를 확인하며, 파일 내용의 정확성이나 악성코드 검사를 대신하지 않습니다. 서버가 파일을 실행하거나 원본 내용을 자동 장부로 확정하지 않습니다. 원본 파일은 DB에 바이트 그대로 저장하고 SHA-256 검증값을 보관합니다. 조회에는 파일 내용을 불러오지 않고 목록 정보만 사용합니다.

원본별 동일 파일의 중복 첨부와 같은 요청 재전송을 보호합니다. 회사 범위를 확인하며, 로그인 후에만 업로드·다운로드·사진 보기를 제공합니다. 파일은 공개 다운로드 폴더에 놓지 않습니다. 다른 출처의 업로드를 차단하고 실제 전송량도 제한합니다.

첨부 취소는 목록 상태를 바꾸고 원본과 사유를 보존합니다. 복원할 때는 같은 파일의 활성 첨부가 없는지 다시 검사합니다. 취소한 첨부도 이력에서 원본을 내려받을 수 있습니다. 귀속월·문서 종류·원본 구분·파일명/설명으로 조회하며 목록은 50건씩 표시합니다.

## 회계 전달본 묶음

귀속월을 입력한 첨부의 목록과 검증값을 전달본에 함께 보관합니다. 전달본 엑셀은 안내+업무자료 10종으로 총 11시트입니다. ZIP 버튼은 그 전달본 엑셀과 생성 당시 활성 상태였던 첨부 원본, 파일명 대응 목록을 함께 제공합니다. 30MB 또는 250개 파일 단위로 나눠 받을 수 있습니다.

이후 첨부를 취소해도 이전 전달본의 ZIP은 당시 보관한 파일을 제공합니다. 내려받을 때 파일 크기·검증값을 다시 대조하며, 다른 회사 파일이나 손상된 원본을 포함하지 않습니다. 변경된 자료는 새 전달본으로 보관합니다. 전달은 사용자가 직접 수행하며 외부 메일·메시지를 자동 발송하지 않습니다.

## 백업

첨부 바이트와 연결·취소 이력은 DB에 있으므로 DB 백업에 포함됩니다. PostgreSQL 17 도구를 설치한 환경에서는 기존 백업 명령을 사용합니다. Linux Docker DB 컨테이너의 도구를 쓸 경우 ERP_PG_TOOLS_CONTAINER에 해당 로컬 컨테이너 이름을 명시할 수 있습니다. 비밀번호는 명령 문자열로 전달하지 않습니다. 실제 업무 DB로 시험 복원하지 않으며 별도 빈 DB에서 복구·파일 검증값을 확인합니다. 예약 백업·보관 정책은 운영 서버 개설 후 설정해야 합니다.

NAS의 기존 원본 폴더는 자동 변경하지 않습니다. 회사 PC에서 NAS 파일을 선택해 첨부하면 ERP에 별도 사본을 보관합니다. NAS 직접 연결·OCR·자동 내용 추출은 별도 범위입니다.
