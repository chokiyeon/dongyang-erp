# 원본 결재 표기와 은행 지급 대조

매입 원본의 `결재일`(34번째 열)에 값이 있으면 실제 지급 완료인지, 예정일/메모인지 원본과 통장을 대조해야 한다. 선택한 행뿐 아니라 같은 승인번호의 전체/월별 품목 행에서 결재 표기를 모은다. 원본의 표기만으로 정산액이나 은행 거래를 만들지 않는다.

미지급 잔액이 있는 해당 청구는 `송금 준비표 → 확인 전 송금 보류`에 남는다. `매입·매출 → 문서 상세 → 원본 결재 표기와 기존 지급 대조`에서 아래 순서로 처리한다.

1. 실제 송금이 있으면 문서의 은행 연결 기능으로 기존 거래를 먼저 연결한다. 이미 전액 연결된 청구는 송금 준비에 나타나지 않는다.
2. 원본 결재 표기의 의미와 기존 지급 내역을 대조하고 현재 남은 금액이 실제 미지급인지 확인한다.
3. 확인 체크와 근거/사유를 기록하면 다른 송금 조건도 충족하는 청구에 한해 송금 준비표에 포함된다. 이 확인은 송금이나 지급 실적을 생성하지 않는다.
4. 잘못 확인했거나 추가 확인이 필요하면 사유와 함께 확인을 철회해 다시 보류한다.

대조 기준은 원본/결재 표기, 거래처 사업자번호, 공사/본사 구분, 증빙일·기한·지급방법, 공급가액·세액·합계·은행 연결액과 현재 유효한 은행 연결 목록이다. 기준이 달라지면 기존 확인은 유효하지 않고 다시 대조해야 한다. 문서 버전, 요청 재시도, 마감 보호와 변경 이력을 적용한다. 회계 전달본에도 원본 표기·은행 연결액·남은 금액·대조 상태와 사유를 보관한다.

이 기능은 송금 준비 출력 대상의 재지급 방지 검토다. 미수/미지급 잔액과 예산 전망은 실제 연결된 지급을 기준으로 계산한다. 결재 메모를 보고 기존 잔액을 자동 차감하거나 세무 판단을 확정하지 않는다. 통장 거래가 아직 이관되지 않았다면 지급 대조와 실제 잔액 확인을 먼저 완료한다.
