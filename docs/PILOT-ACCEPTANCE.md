# 경리 시범운영 전 완료 기준

사용자는 2026-11-05 상계 거래가 연 1~2건 이하라고 설명했다. 자동 상계는 후순위로 두고 빈번한 경리 업무를 먼저 완성한다. 공무는 현재 개발 범위에서 제외한다.

## 개발 환경에서 확인할 핵심 경로

- 기존 엑셀 통장 장부·매입매출·어음·예산 배치를 유지하고 불명확한 원본을 보류한다.
- 출역 자료에서 상용/일용 구분, 날짜별 공수·단가·공제 검토를 거쳐 급여대장·1쪽 명세서·이름별 JPG와 지급 예정으로 연결한다.
- 다음 달 말일·즉시 지급·월세·공과금·급여의 수취계좌와 공사 구분을 송금표로 출력한다.
- 미수·미지급, 수정 계산서, 부분/전액 취소, 기지급 환급, 재발급, 자재 반환, 공사 배부·차량 정산이 원본 및 과거 마감월을 보존한다.
- 현금 시제·실제 보관액 대조, 은행 잔액 대조, 원가 중복 방지, 공사별 손익, 월마감·회계 전달 및 첨부 백업/복구가 연결된다.
- 접근 인증·회사 범위·중복 요청·낡은 버전·동시 잔액 초과·마감 보호와 설치 사전 점검이 작동한다.

## 실제 회사에서 확인할 항목

회사 원본의 형식 변형, 실제 직원 매핑·현장 약칭, 계약 단가·세금·보험의 확정 기준, 기초 잔액·재고·실현금, 기존 비용 중복, 회계사무소 전달 기준을 짧은 기간부터 대조한다. 메인 PC 설치·실행·사내 주소, NAS 파일 접근·첨부 및 백업/복구·예약 실행을 확인한다.

현행 급여/세무 기능은 확인한 공제 및 세무 기준을 입력하는 방식과 추정 계산을 포함한다. 법정 세액·보험료와 기관 신고를 자동 확정하는 프로그램이라고 안내하지 않는다. 직원별 권한, 은행별 대량 이체 파일, 손글씨 무검토 자동등록 등 확장 기능은 구현되지 않은 상태이며 기본 경리 흐름과 구분한다. 이 항목을 완료로 숨기지 않는다.

검사 결과와 남은 구현을 확인하기 전 '회사 운영검증만 남음'이라고 표시하지 않는다. 최종 다운로드는 검증한 커밋·스키마와 일치하는 압축본으로 만들고 파일명은 짧게 한다. 코드 압축본을 PostgreSQL·Node가 포함된 독립 실행 설치 파일로 표현하지 않는다.

## 2026-11-05 검증 결과

핵심 경리 시범운영 준비 범위에서 전체 자동 검사 243개, 현금/월말 집중 6개, 타입·lint·운영 빌드, 57개 마이그레이션 별도 DB 백업/복구를 통과했다. 전체 화면 56개는 첫 실행 52개 통과 후 검사 선택자 2개 수정·재검증, 기존 자료 보호를 위해 생략한 예산안/마감 2개 별도 DB 검증으로 모두 확인했다. 회사 실자료·실송금·신고·Windows/NAS 운영은 실행하지 않았다.

다운로드는 소스와 설치/실행 스크립트 묶음이다. Node.js·PostgreSQL이 포함된 독립 설치 파일이 아니다. 회사 PC에 설치한 뒤 기존 장부의 짧은 기간 복사본으로 실제 기준을 확인한다. 확인 중 차이나 필요한 예외가 발견되면 운영 전환 전 보완한다.
