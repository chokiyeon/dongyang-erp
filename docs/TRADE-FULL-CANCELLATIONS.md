# 미정산 전액취소 수정증빙

매입매출 원본 검토에서 음수 수정증빙을 선택해 같은 달의 미정산 세금계산서 원본과 연결한다. 사업자번호·매입/매출 구분·공급가액·세액·합계가 전액 반대 금액으로 일치해야 한다. 후보가 여러 개면 원본 관리번호·승인번호를 직접 대조해 선택한다. 숫자·날짜·셀 오류, 파일 내 충돌/중복이 있는 행은 처리하지 않는다.

지급/수금·예산안·정기지급이 연결된 원본은 이 경로에서 취소하지 않는다. 원가 배부·차량·입고 연결도 기존 청구 취소 보호를 적용한다. 부분 감액·이미 지급한 금액의 환급·다른 달 수정은 별도 미완료 정산 범위이며 단순 취소로 대신 처리하지 않는다.

원본 청구를 취소해 같은 달의 채권채무·원가·부가세 추정에서 제외하고, 음수 수정증빙은 별도 이력으로 보관한다. 음수 증빙을 금액에 다시 더하지 않는다. 실제 은행 거래나 자금예정을 새로 만들지 않는다. 국세청 발급·취소를 실행하는 기능이 아니다.

## 보존과 입력 정정

회사별 원본 파일은 SHA256 기준 한 번만 보관한다. 원본/수정 승인번호·시트·행·원본 셀과 사유를 보관하고 회계 전달본/원본 ZIP에 포함한다. 원본 승인번호와 수정 승인번호를 일반 활성 청구에 다시 쓰지 못하도록 회사 기간 잠금 아래에서 검증한다. 같은 요청이 동시에 도착해도 한 번만 반영한다.

잘못 연결한 ERP 입력은 수정증빙 상세의 ‘입력 오류 정정’으로만 되돌린다. 원본이 변하지 않았고 같은 월이 열려 있어야 한다. 원본 청구를 복원하고 수정증빙은 등록 정정 이력으로 남긴다. 실제 세금계산서의 법적 취소를 철회하는 작업이 아니다. 이미 반영한 수정증빙을 물리 삭제하지 않는다.

공사 원가·미지급과 부가세 추정이 원본 취소로 바뀌고 등록 정정 시 복원되는지, 동시 재시도·마감 보호·승인번호 재사용·원본 ZIP을 합성 자료로 검증했다. 실제 회사 자료 자동 처리나 모든 수정 거래의 구현 완료를 뜻하지 않는다.
