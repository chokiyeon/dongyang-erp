# 기존 장부 검토와 분류 개선

검토 자료: 사용자가 제공한 `장부-기연..xlsx`. 원본은 읽기 전용으로 검토했으며 수정하지 않았다. 거래 금액·계좌번호·개인 이름을 문서에 복사하지 않는다.

## 확인한 구조

2012~2026년 장부와 별도 대출·분류 시트 등 23개 시트가 있다. `품목분류`는 세무 계정과목만을 모은 표가 아니라 본사/현장·지급수단·업무 목적이 섞인 현금 입출금 분류다.

- `본(차량)` 설명에 주유·수리·할부·보험이 함께 들어 있다. 차량 유지비, 자산·차입 원금, 이자, 보험료는 같은 의미가 아니다.
- 본사/현장 카드 코드가 있다. 카드 사용 목적과 결제 시 미지급금 지급을 구분해야 비용이 중복되지 않는다.
- 세금 코드가 넓게 묶여 있다. 전기·수도·가스, 자동차세, 부가세, 법인세, 과태료를 같은 기준으로 고르기 어렵다.
- 보험료 설명에 4대보험·근재가 함께 있다. 직원 공제 예수금과 회사 부담 보험료가 섞일 수 있다.
- 공사비 입금·차입금 입금·어음 등은 수금/금융 방식이며 모두 매출이 되는 것은 아니다.

이 구조만으로 과거 개별 거래의 정답을 확정하지 않는다. 환급·대납·정산 등 다른 성격일 수 있으므로 과거 장부를 키워드로 일괄 재분류하지 않았다.

## 새 화면 원칙

숫자 암기 대신 '무엇을 지급·수금했나요?'에서 업무 이름을 선택하고 연결 계정과 주의사항을 확인한다. 본사·현장과 계약 목적이 달라지는 항목은 별도 선택한다.

| 거래 | 분류 안내 |
|---|---|
| 사무실 전기·수도·가스 | 수도광열비 |
| 현장 전기·수도·가스 | 현장 수도광열비 |
| 자동차세 | 세금과공과 |
| 과태료·범칙금·벌금 | 별도 계정, 세무조정 확인 |
| 정수기·복합기 일반 렌탈 | 지급임차료, 구입 할부·금융리스 여부 확인 |
| 현장 장비 대여 | 장비임차료, 보증금·구입대금 제외 |
| 차량 일반 렌트 | 지급임차료, 금융리스·할부 계약과 구분 |
| 카드대금·기존 매입대금 결제 | 미지급금 결제, 원래 비용 중복 방지 |
| 확정 급여 지급 | 급여미지급금 결제, 세전 원가·개인 공제와 대조 |
| 대출 원금+이자, 4대보험 합산 | 미분류·확인 필요, 내역에 따라 분리 |

장부 내 거래의 계정 수정은 원래 일자·금액·잔액을 유지하고 수정 이력을 남긴다. 이 기능은 거래 분류 보조이며 자동 세무 신고나 회계 분개 전체를 구현한 것은 아니다.
