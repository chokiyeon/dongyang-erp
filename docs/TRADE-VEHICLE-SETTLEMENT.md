# 같은 달 차량 연결 계산서의 수정 정산

한 차량 비용과 한 매입 계산서를 금액·공사·본사 구분으로 대조한 상태에서 같은 달 음수 수정증빙을 처리한다.

- 부분 감액: 계산서의 현재 순액과 연결 차량 비용의 금액을 함께 맞춘다. 기존 차량 비용 행·증빙·원 은행 거래를 보존하며 새 비용을 중복 생성하지 않는다.
- 전액취소: 연결 차량 비용을 이력으로 보존해 취소한다. 이미 지급한 은행 거래는 그대로 두고 실제 환급은 별도로 대조한다. 미지급 취소로 가짜 환급을 만들지 않는다.
- 입력 정정: 현재 차량 비용·취소 상태와 복원 금액을 비교하고 확인한다. 원 청구와 차량 비용을 함께 복원한다. 차량 또는 비용이 후속 변경되면 정정 화면을 다시 열어 현재 버전을 확인한다.
- 공사 배부가 같이 연결된 경우: 차량 정산과 현장/본사 원가 재배부를 하나의 트랜잭션에 저장한다. 어느 하나가 실패하면 계산서·원가·차량·예정 변경 전체를 롤백한다.

엑셀 검토에서 같은 달 감액/전액취소 원 청구를 선택하면 차량 번호, 비용 관리번호, 현재 금액과 수정 후 처리 내역을 표시한다. 차량 비용 확인을 별도로 체크해야 저장할 수 있다. 차량대장에는 계산서 감액/취소/입력 정정 처리 이력을 한국어로 표시한다.

원 차량 비용의 회사 부담·현장/본사·금액·발생월·버전을 대조한다. 기존 독립 은행 지급이나 별도 차량 총원가 배부가 있으면 보류한다. 다른 달 차량 정산은 과거 장부 보존 처리가 필요해 지원하지 않는다. 일반 문서 취소로 차량 연결 보호를 우회하지 않는다.

차량 원본의 설명·증빙은 유지하며 정산과 입력 정정은 금액·취소 상태를 처리한다. 실제 은행 거래를 임의로 지우거나 세금계산서를 외부 기관에서 발행/취소하지 않는다. DB 스키마 추가·초기화 없이 기존 VehicleChange와 TradeDocumentChange의 감사 이력을 사용한다. 회사 실자료·PC/NAS 운영 검증은 별개다.

검증: 전체 단위/DB 214개, 차량·공사 집중 23개, 최신 차량 집중 10개, 관련 화면 9개 흐름, 타입/lint/운영 빌드 통과. 모든 검사 자료는 합성 자료다.
