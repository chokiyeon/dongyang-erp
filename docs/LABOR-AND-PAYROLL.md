# 직원·계약·현장 출역·월별 급여 검토

## 등록 순서

인사·급여 → 직원·계약 단가에서 직원 코드, 이름, 일용·일당제 또는 사무실 월급제, 입사일·퇴사일을 등록합니다. 같은 이름이어도 직원 코드로 구분합니다. 주민등록번호나 기존 급여 파일의 개인정보를 자동 가져오지 않습니다.

직원을 선택해 적용일별 계약을 등록합니다. 일용직은 근로계약서의 실제 지급 일당을 일반 작업·신호수로 각각 등록합니다. 작업일 이전의 가장 최근 계약을 적용하며 신호수 계약이 없을 때 일반 단가로 대신 계산하지 않습니다. 월급제는 일반 구분의 월 계약 기준액만 등록합니다.

현장 출역·공수에서 직원·현장·작업일·작업 구분·공수·원본 메모를 저장합니다. 소수 둘째 자리 공수를 정수 연산으로 계산하며 원 미만 결과는 임의 반올림하지 않습니다. 같은 직원·날짜·현장·작업 구분의 중복을 막습니다. 같은 날 여러 현장에 근무한 내역은 입력할 수 있습니다. 1공수 초과는 검토 대상으로 표시하고 자동 삭감하지 않습니다. 사무실 월급제는 작업일보를 입력하지 않습니다.

## 계약·출역 정정

변경 사유와 전후 내용을 보존합니다. 이미 사용한 계약을 수정해도 저장한 출역의 일당·금액을 덮어쓰지 않습니다. 월별 급여 검토에서 계약 변경을 표시하며, 원본을 대조하고 해당 출역을 다시 저장하면 당시 작업일에 적용되는 계약으로 재계산합니다. 사용 중인 출역이 있는 계약은 취소할 수 없습니다. 출역 취소는 월 합계에서 제외하고 원래 기록과 사유를 남깁니다.

직원 이력·계약·출역은 회사 범위를 확인하고 버전·요청 식별자로 동시 수정과 재요청을 보호합니다. 출역·계약 이력이 있으면 고용 구분을 바꾸지 않습니다. 입·퇴사일을 바꿔 이미 등록한 출역이 고용 기간 밖으로 밀려나는 변경도 거절합니다.

## 월별 검토·출력

월별 급여 검토에서 직원별 공수와 실제 지급 일당 계산액을 여러 현장에 걸쳐 합산합니다. 같은 화면에 현장별 상세와 사무실 월급 기준을 구분합니다. 출역 없음, 하루 1공수 초과, 계약 변경과 월중 입·퇴사/월급 계약 변경을 표시합니다. 확인사항이 없다는 표시는 등록된 자료 범위일 뿐 출역 원본의 완전성 확인을 대신하지 않습니다.

미리보기·프린트·엑셀로 저장으로 직원별 일용직 지급 검토, 현장별 지급 검토, 사무실 월급 기준 3개 표를 출력합니다. 조회 조건과 등록 양식은 출력하지 않습니다. 출역 목록은 최대 500건이지만 월별 합산은 해당 월 전체를 사용합니다.

## 현재 범위

계산액은 실제 지급 일당 기준 검토액이며 노무 신고 금액·총 노무 원가·세금·보험료·회사 부담분이 아닙니다. 이를 공사 손익의 발생원가에 자동 가산하지 않습니다. 월급 기준액 역시 실제 지급액 확정이 아닙니다. 기존 수기 인건비·은행 지급을 중복 합산하지 않아야 합니다.

사진·엑셀에서 출역 자동 추출, 노무 신고 대장과 보험·세액 자동 산정, 총 노무 원가의 확정·공사 손익 배부는 후속 범위입니다. 기존 급여 원본 파일을 수정하거나 실데이터를 시험 자료로 사용하지 않았습니다.

## 최종 실지급액 확인과 송금

직원 정보에 급여 송금 은행·계좌번호·예금주를 등록하고 통장 사본으로 확인합니다. 변경 사유와 이전·새 정보는 직원 이력에 남습니다. 계좌 확인을 하지 않으면 송금표에서 보류합니다.

급여 지급 확인에서 지급월과 직원을 선택합니다. 일용직은 등록 출역의 계산액을 기본으로 보여 주며 다른 금액을 쓰려면 조정 근거가 필요합니다. 월급제는 계약 기준액을 실지급액으로 복사하지 않습니다. 실제 수당·공제 등을 대조해 최종액과 산정 근거를 직접 입력합니다. 일용직 계약 일당은 실지급 기준이므로 세금·보험을 자동 재차감하지 않습니다.

공수 초과·월중 변동 등 확인사항, 최종 실지급액과 기존 지급 예정의 중복이 없음을 확인해 저장합니다. 같은 직원·지급월은 하나의 확인 내역으로 관리합니다. 확인 시 공수·계약 근거를 보존합니다. 다른 화면에 별도 급여 예정이 있으면 먼저 원본을 확인·정리한 뒤 등록해야 합니다.

등록한 직원별 지급 예정은 자금계획과 송금 준비표에 연결됩니다. 직원별 여러 현장 금액을 한 번에 지급하므로 송금 준비표의 전체 현장·본사 조회에서만 표시합니다. 특정 현장 조회에 전체 직원 급여를 섞어 현장 지급액으로 표시하지 않습니다.

확인 후 출역·계약이 바뀌면 송금표에서 보류합니다. 미지급 상태에서 다시 확인하면 종전 예정을 종료하고 새 확인액으로 대체합니다. 지급 실적이 있으면 급여 금액 변경·예정 취소를 막고 실제 은행 지급 이력을 먼저 확인하도록 합니다. 이는 지급 완료된 급여를 임의 재계산하거나 법적 채무를 감액하는 기능이 아닙니다.

송금 준비표의 지급 내역 연결에서 기존 은행 출금을 연결합니다. 부분 지급은 남은 급여만 송금표에 남고 전액 지급은 제외됩니다. 실제 처리 취소 시 잔액이 복원됩니다. 정기 월세·공과금 원본으로 급여 지급 예정을 재사용할 수 없습니다.

인쇄·엑셀 저장은 송금 실행이 아닙니다. 실지급액과 총 노무 원가는 다르므로 확인한 지급액을 손익에 자동 가산하지 않습니다. 공제·신고·회사 부담분을 포함한 원가는 별도 검토해야 합니다.

## 상용직 수당·공제 세부 저장

월급제 직원의 `급여 지급 확인`에서 세부 계산을 선택할 수 있다. 기본급·직무/연장/휴일/자격/연차수당·차량유지·식대보조, 지각조퇴/결근 공제, 소득세·주민세·연금·고용·건강·장기요양·가불금기타 및 연말정산 조정액을 원 단위로 입력한다. 해당 없음은 0을 명시하며 빈칸을 자동 0 처리하지 않는다.

지급총액은 지급항목 합계에서 근태공제를 뺀 금액, 실수령액은 지급총액에서 제세/기타 공제를 빼고 연말정산 조정액을 더한 금액이다. 조정액은 환급 양수, 추가공제 음수로 표시한다. 입력 금액의 단순 합산이며 근무시간에 따른 수당 산정·세율/보험요율 자동 산정은 아니다. 원본의 과거 반올림/요율을 복사하지 않는다.

계산 실수령액과 최종 실지급액이 같아야 저장한다. 세부 내역은 지급 확인 당시의 기존 `PayrollPayment.snapshot`에 버전 1의 `monthlyDetails`로 보관하고 변경 전후 스냅샷을 이력에 남긴다. 별도 테이블이나 DB 변경 없이 기존 지급 예정·은행 연결·원가 재검토 흐름을 따른다. 이전에 세부 내역 없이 확인한 지급도 그대로 읽을 수 있다. 세부 내역을 저장한 지급을 내역 없이 덮어쓰는 것은 막는다. 실제 지급 실적이 있는 급여는 기존대로 변경·취소를 제한한다.

상용직 임금대장과 미리보기·엑셀에는 저장한 수당·공제·지급총액·공제합계·연말정산 조정액을 반영한다. 직책·부양가족·시급·근무시간은 아직 입력 대상이 아니며 미입력으로 남긴다. 일용직의 실지급 일당에는 이 공제 계산을 적용하지 않는다.

## 일용직 월별 공수 일괄 등록

`현장 출역·공수 → 월별 공수 일괄 입력`에서 한 직원·현장·작업 구분의 여러 날짜를 등록한다. 날짜별 실제 계약 일당을 적용하며 월중 단가 변경도 구분한다. 빈칸/0은 신규 출역으로 만들지 않는다. 기존 출역은 입력을 막고 수정 링크로 연결한다. 미래 날짜·고용기간 밖·누락 계약·중복 출역 등 기존 검증을 그대로 적용한다.

이번 묶음의 한 날짜라도 오류면 트랜잭션 전체를 롤백한다. 직원 버전으로 동시 수정과 계약 변경을 확인하고, 묶음 및 날짜별 요청 ID/감사 이력을 보관한다. 같은 요청 재전송은 추가 등록하지 않으며 내용이 다른 재사용은 거부한다. 이미 다른 현장에 입력한 공수는 기존 급여 검토에서 직원별로 합산한다.

## 세후 → 세전 급여 계산기

`인사·급여 → 급여 역산 계산기`에서 목표 실수령액을 만원 단위로 입력한다. 확인한 근로자 부담 월 공제액을 더하는 방식과 직접 입력한 합산 공제율/별도 고정공제액으로 추정하는 방식을 제공한다. 조건 변경 시 기존 결과를 지워 오래된 금액을 사용하지 않도록 한다.

공제율 방식은 `세후 = 세전 − floor(세전 × 입력율) − 고정공제`를 만족하는 최소 원 단위 세전을 BigInt 이진 탐색으로 구한다. 예시 10%·고정공제 0원·세후 2,500,000원이라면 세전 2,777,777원, 비율공제 277,777원이다. 10%는 검증용 가정으로 법정 요율이 아니다. 보험료 상하한·세액표·비과세·부양가족에 따른 공식 계산이 아니며, 해당 월 조건으로 실제 급여를 확인해야 한다. 결과는 급여대장에 자동 저장하지 않는다.

## 원본형 급여 엑셀

급여대장 화면의 `상용직 원본형 엑셀 저장` / `일용직 원본형 엑셀 저장`은 `/api/payroll-register`의 인증된 전용 파일을 받는다. 화면 캡처 기반 공통 엑셀과 별도로, 실제 두 줄 행과 병합 셀·반복 머리글·가로 인쇄·고정 행/열을 가진 XLSX를 생성한다. 상용직은 8월 원본의 21열 수당/공제 배치다. 일용직은 위 1~15일/아래 16~월말 공수와 공수 합계/일당을 두 줄로 두고 직원별 지급 합산을 별도 시트로 만든다.

내보낼 월 자료와 지급 확인 자료를 Repeatable Read로 함께 읽는다. 공수 묶음은 화면/엑셀이 같은 집계 함수를 사용한다. 15자리를 넘는 금액은 Excel 정밀도 손실을 막기 위해 숫자 문자열로 보존한다. 원본 수식을 복사하거나 알 수 없는 공제액을 0으로 채우지 않는다. 일용직의 현장별 계산액에 직원 통합 최종 지급액을 반복 기입하지 않는다. 변경된 계약/출역과 지급 확인의 불일치는 검토 메모에 남긴다.

본표는 A3 가로·폭 한 장 맞춤, 합산표는 A4 가로 인쇄 설정을 포함한다. 프린터 지원 용지에 따라 Excel에서 용지 크기를 바꿀 수 있다. 웹의 공통 인쇄/엑셀 기능도 유지한다. 파일은 로그인한 관리자만 내려받을 수 있으며 응답을 캐시하지 않는다.

## 직원별 급여명세서 검토

`급여 지급 확인 → 개별 급여명세서`에서 한 직원·한 지급 확인의 검토용 명세서를 조회하고 공통 미리보기·프린트·엑셀을 사용할 수 있다. 화면은 로그인한 관리자만 조회하며 회사 소유 지급 건만 찾는다. 다른 직원의 급여 표는 포함하지 않는다. 수취계좌는 현재 등록된 은행/예금주와 끝 네 자리만 표시한다.

상용직은 지급 확인 스냅샷의 수당·근태공제·제세/기타공제·연말정산 조정과 합계를 표시한다. 일용직은 저장 당시 출역 날짜·현장 ID·역할·공수·일당·계산액을 사용한다. 현재 수정된 출역으로 과거 명세서의 금액을 바꾸지 않으며 현장 명칭은 현재 등록 명칭임을 밝힌다. 출역 스냅샷의 날짜/금액/중복이 잘못되면 세부 출역은 표시하지 않고 검토 안내를 띄운다. 직원·기간이 다른 스냅샷도 표시하지 않는다.

계약/출역이 변경됐거나 지급 확인이 취소됐거나 공제 내역이 없으면 재검토 안내를 표시한다. 실제 지급 실적은 지급예정일과 구분하며 취소된 실적은 유효 합계에서 제외한다. 조정된 일용직 지급액과 출역 계산액의 차이를 표시하고 조정 근거를 대조한다.

항상 검토용으로 표시한다. 근로시간·시급/수당 산식·공제 근거 등 임금명세서의 필수 항목을 모두 확보한 공식 발급/교부 완료 기능은 아니다. 직원에게 전송하거나 교부 이력을 생성하지 않는다. DB 스키마와 실제 원본 자료를 바꾸지 않는 조회 기능이다.

## 한 장 임금명세서와 근로자명 JPG

첨부 임금명세서 PDF의 첫 페이지를 기준으로 지급·수당/공제를 좌우로, 실수령액을 아래에 배치했다. 노란 항목 칸·살구색 금액 칸·회사명 하단 영역을 사용한다. 상용직의 모든 저장 수당/공제 항목과 연말정산 조정액을 표시하며, 일용직에도 항목명을 표시하되 확인되지 않은 세부 금액은 미확인으로 남긴다. 일용직 공수 합산 실지급 기준액에서 세금을 다시 차감하지 않는다. 일수/공수와 단가는 저장 자료가 있는 경우만 표시하며 상용직 시급/근무일수를 계약 월액에서 역산하지 않는다.

명세서 페이지와 전용 XLSX는 공통 데이터 로더를 사용한다. 한 직원·한 급여월의 XLSX 한 시트, A4 세로 폭/높이 한 장 맞춤, 해당 영역만 인쇄하도록 설정했다. 화면의 명세서 전용 미리보기는 지급/공제 표를 평면 표로 재조합하지 않고 동일한 양식을 그대로 출력한다. 공통 미리보기·프린트·엑셀 버튼도 이 페이지에서는 전용 출력으로 연결한다. 상세 출역/실제 지급 이력은 펼침 영역에서 확인하며 본문 출력에 불필요한 페이지를 추가하지 않는다.

`근로자명 JPG 저장`은 현재 한 직원의 명세서만 A4 비율 1240×1754 JPEG로 저장한다. 파일명은 `근로자이름_급여월_임금명세서.jpg`이며 Windows 파일명에서 사용할 수 없는 문자를 치환한다. 브라우저에서 화면을 렌더링해 한 이미지에 맞추므로 한글 글꼴과 항목이 유지된다. 파일만 내려받으며 직원에게 문자나 다른 메시지를 전송하지 않는다. 출력 자료는 현재도 원본 근거 대조가 필요한 검토용이다.

## 일용직 전용 명세서: 일당·일수 − 공제

사용자의 수정 요청에 따라 일용직 지급 항목은 `일당`, `일수` 두 항목만 표시한다. 기본급·연장/휴일수당·식대 등 상용직 지급 항목을 일용직 명세서에 나열하지 않는다. 지급총액은 공제 전 일당 × 일수의 합계, 실지급액은 지급총액 − 공제합계다. 소득세·주민세·고용보험·국민연금·건강보험·장기요양·노조조합비·기타공제를 원 단위로 확인해 입력한다.

일용직 지급 확인 화면에 공제 전 일당과 공제 내역 입력을 추가했다. 일수는 등록 출역 공수를 합산하고 일반/신호수 및 적용 단가 구간별로 나눈다. 각 구간의 공제 전 일당은 별도 확인하며 기존 실지급 기준 계약 일당을 자동 복사하지 않는다. 따라서 과거 실지급 일당에서 공제를 중복 차감하지 않는다. 소수 일수는 두 자리까지 계산하고 원 미만 결과·과다 공제·저장 범위 초과를 거부한다.

확인한 값은 지급 스냅샷의 `dailyDetails` 버전 1로 저장한다. 계산 실지급액과 최종 확인액이 일치해야 저장하며, 기존 세부 내역 생략·기준 변경·지급 후 수정을 기존 보호 규칙으로 제한한다. 상용직 월급 계산과 분리한다. 새 세부 내역이 없는 과거 지급은 공제 전 금액을 추정하지 않고 재확인이 필요하다고 표시한다.

화면·개별 XLSX·JPG는 같은 일용직 데이터를 사용한다. 일반/신호수 일당이 둘 이상이면 각각의 일당·일수를 한 셀에서 줄바꿈해 표시하고 지급총액에 한 번씩 합산한다. Excel 행 높이도 긴 일당/일수 표시에 맞추며, A4 한 장과 근로자명 JPG 저장을 유지한다.

### 일용직 표시 항목 정정: 공수·일수

최신 요청에 따라 일용직 지급 항목은 `공수`, `일수`로 표시한다. 공수는 지급 확인 당시 출역 공수의 합계이고, 일수는 같은 날 여러 현장/역할로 출역해도 한 번만 세는 실제 출역 날짜 수다. 예: 같은 날 0.5+0.5공수, 다음 날 1.5공수이면 합산 2.50공수·2일이다.

기존 공제 전 계산과 최종 지급액은 바꾸지 않는다. 표시명은 `실지급 기준 계산액 (공제 전)`으로 두고, 확인 일당 × 합산 공수로 산정한 금액에서 공제합계를 차감한다는 근거를 적는다. 실제 출역일수와 합산 공수를 동시에 금액에 곱하지 않는다. 상용직 수당 항목은 일용직 명세서에 표시하지 않는다. 검토용 샘플 파일은 이전 이미지와 구분하도록 새 파일명을 제공한다.

### 일용직 기존 PDF 양식 반영 (2026-11-01)
- 첨부된 기존 일용직 명세서의 지급액·일수·단가 / 지급합계액·공제액 / 실 수령액 항목을 화면과 엑셀에 적용한다. 상용직 수당은 표시하지 않는다.
- 일수는 계산에 사용한 공수 합계로 명시한다. 실제 출역 날짜 수를 곱해 반일·연장분이 사라지지 않도록 한다. 단가가 여러 개면 작업 구분별 단가와 일수를 표시한다.
- 요양보험을 포함한 공제는 저장된 확인 금액을 사용한다. 날짜가 다른 원본의 하단 날짜를 지급일로 복사하지 않고 저장된 지급예정일을 표시한다. 실명·원본 급여·도장은 예제나 소스에 복제하지 않는다.

### 직원별 JPG 묶음 저장
- 급여 지급 확인에서 ‘급여명세서 모아 저장’으로 이동해 귀속월과 상용직/일용직을 조회한다. 취소된 지급 확인은 제외한다.
- 한 번에 최대 30명을 선택해 ZIP으로 내려받는다. ZIP 안에는 선택한 직원별 이름_귀속월_임금명세서.jpg만 포함된다. 동명이인·파일명 정규화 충돌에는 번호를 붙여 덮어쓰기를 막는다.
- 각 명세서는 내려받는 시점에 회사 범위와 로그인, 저장 기준 변경·미확인 항목을 다시 검사한다. 재검토가 필요한 직원이 있으면 ZIP 저장을 중단하고 이름과 정정 안내를 표시한다.
- 브라우저에서 한 장씩 JPG를 생성하며 한 명이라도 실패하면 부분 ZIP을 저장하지 않는다. 처리 중 선택을 잠그고 진행 인원을 안내한다. ZIP과 JPG를 서버에 보관하거나 문자로 발송하지 않는다.
