# 송금 준비표·월세·공과금

자금 관리 → 송금 준비표에서 기준일까지 기한이 도래한 미지급 매입과 확인한 정기 지급을 모읍니다. 기한이 지난 미지급도 포함하며 현장 또는 본사·공통 지급으로 조회합니다.

## 지급 조건과 계좌 등록

거래처 관리에서 은행·계좌번호·예금주를 등록하고 통장 사본 등으로 확인한 뒤 확인 표시와 변경 사유를 저장합니다. 확인하지 않은 계좌는 보류합니다. 계좌 변경 이력을 남깁니다.

거래처 지급 조건은 직접 지정·즉시 지급·다음 달 말일로 설정합니다. 9월 청구의 다음 달 말일은 10월 31일입니다. 새 매입은 거래처 조건을 기본으로 사용하며 매입별로 변경할 수 있습니다. 거래처 조건 변경만으로 기존 청구 기한이 바뀌지 않습니다. 계좌 송금·어음 등 지급방법, 원본 증빙 확인과 현장 또는 본사·공통 구분도 저장합니다.

## 월별 정기 지급

1. 월세·공과금 정기 지급에서 거래처, 현장 또는 본사, 기본액과 지급일을 등록합니다. 지급일 0은 말일이며 변동 요금은 기본액을 비워 둡니다.
2. 지급월을 선택하고 이 지급월 정기 내역 준비를 누릅니다. 같은 기준의 같은 월은 중복 생성하지 않습니다.
3. 이번 달 금액·기한을 확인하고 기존 매입 청구자료 또는 지출 예정에 연결합니다. 같은 비용의 원본이 없는 경우에만 중복이 없음을 확인해 새 지출 예정을 만듭니다.
4. 월별 확인을 저장합니다. 기존 매입에 연결한 정기 지급은 매입 한 건으로 송금표에 표시합니다. 기준 수정으로 이미 준비한 월의 금액이 바뀌지 않습니다.

## 인쇄와 송금 후 처리

송금 준비표에서 최신 내역으로 조회한 뒤 이번에 지급할 항목을 선택합니다. 거래처·은행·계좌·예금주가 같으면 합산하고 공사별 금액도 표시합니다. 상단 미리보기·프린트·엑셀로 저장은 선택한 거래처별 합산표와 공사·청구별 상세만 출력합니다. 계좌번호 앞의 0도 보존하며 합산표에 이체 확인란을 표시합니다.

각 항목의 지급 내역 연결을 누르면 매입의 은행 연결 또는 정기 지급의 실제 처리 화면으로 이동합니다. 실제 송금 후 은행 거래를 연결하고 송금표를 다시 조회하세요. 일부 지급은 남은 금액만 표시하고, 전액 완료는 제외하며, 처리 취소 시 남은 금액을 복원합니다. 지급 내역 연결 버튼과 선택용 목록은 출력하지 않습니다.

금액·기한·현장·지급방법·증빙·수취계좌가 미확인인 내역은 보류합니다. 어음·기타 지급은 계좌 송금 대상에서 제외합니다. 기준월 정기 지급이 준비되지 않았다면 안내합니다.

출력은 은행 이체나 지급 완료를 실행하지 않습니다. 송금 직전에 계좌와 금액을 대조하세요. 정기 지급 등록만으로 세금계산서·부가세·공사 발생원가는 생성되지 않습니다. 월별 정기 지급을 취소해도 연결한 매입 자체는 취소되지 않습니다.

## 직원 급여

급여 지급 확인에 등록한 직원별 최종 실지급액도 전체 현장·본사 조회에서 모읍니다. 수취계좌 미확인, 급여 확인 후 출역·계약 변경은 보류합니다. 지급 내역 연결로 은행 지급을 반영하면 남은 금액만 표시합니다. 특정 현장 조회에서는 여러 현장을 합산한 직원 급여를 제외합니다. [급여 확인 기준](LABOR-AND-PAYROLL.md).
