# 같은 달 수정증빙과 공사 원가 배부

이미 여러 공사에 배부한 매입을 같은 달 음수 수정세금계산서와 함께 정산한다. 계산서 감액/취소와 원가 배부를 한 트랜잭션에 저장한다. 기존 금액을 지우지 않고 배부 변경 이력에 전후 내역을 보관한다.

## 부분 감액

1. 매입매출 엑셀 검토에서 음수 행의 부분 감액 검토(기지급이면 기지급 부분 감액)를 연다.
2. 원 청구를 선택하면 기존 총원가·현장별 금액·본사 공통액을 조회한다.
3. 감액 후 현장별/본사 금액을 직접 입력하고 확인한다. 임의 비율로 자동 배부하지 않는다.
4. 배부 합계는 매입세액 공제 여부를 반영한 순원가와 일치해야 한다. 공제 가능이면 공급가액, 불공제면 공급가액+세액이다. 부가세 검토가 미확정이면 먼저 원본을 확인한다.

실제 은행 지급은 보존한다. 미지급 예정은 순액으로 맞추고 기지급 초과분은 기존 환급 검증을 적용한다. 원가를 환급 금액으로 다시 가산하지 않는다. 배부를 바꾸면 해당 공사의 손익 검토도 다시 요구한다.

## 전액취소

같은 달 전액취소 검토에서 기존 총원가와 현장/본사 배부를 함께 취소하는 것을 확인한다. 기존 배부를 삭제하지 않고 비활성화하며 현장별 원가 반영도 취소한다. 미지급 취소는 실제 환급을 만들지 않고, 기지급 취소는 원 지급액을 보존해 별도 환급으로 대조한다. 자재·차량·정기 지급의 별도 검증을 우회하지 않는다.

부분 감액 뒤 잔액을 취소할 때는 남은 순원가만 취소한다. 선행 감액의 환급과 잔액 취소 환급을 중복하지 않는다.

## 입력 정정

수정증빙 상세의 입력 오류 정정에서 현재 배부와 수정증빙 반영 전 배부를 비교한다. 확인 후 청구와 원 배부를 함께 복원한다. 후속 배부 변경이 있으면 정정 화면의 버전이 만료되어 다시 조회해야 한다. 후속 감액/취소는 최근 것부터 정정하고, 환급한 은행 실적은 기존 규칙에 따라 먼저 확인한다.

후속 배부가 존재하더라도 재조회한 현재 내역과 복원 내역을 명시 확인해야 이전 배부로 복원한다. 별도 은행 거래·공사 원가를 새로 중복 생성하지 않는다.

## 기간과 자료 보호

현재 구현은 같은 달, 원가 발생일=원 청구 발행일인 배부를 대상으로 한다. 다른 달 부분 감액은 TRADE-COST-PERIOD.md의 기간별 차액 경로를 지원한다. 다른 달 전액취소 배부는 별도 개발 범위다. 기존 배부가 변경·미확인된 경우 먼저 대조한다. 마감월, 다른 회사 현장, 중복 현장, 합계 불일치, 낡은 버전, 확인 누락을 거부한다.

기존 요청의 지문 형식은 원가 배부를 지정하지 않으면 유지한다. 원가 정산은 기존 SourceCostChange의 전후 스냅샷과 TradeDocumentChange의 정산 참조를 사용한다. DB 스키마 추가나 초기화는 없다. 회사 실자료 자동 이관·실제 송금·세금계산서 발행/취소는 실행하지 않는다.

검증 기록: 전체 단위/DB 204개, 관련 집중 25개, 관련 화면 10개 흐름, 타입/lint/운영 빌드 통과. 화면 검사의 필수항목/선택 목록 접근성 이름과 정정 완료 문구를 실제 표시 기준으로 맞췄다.
