# 현장별 지급예산

공사 관리 → 현장별 지급예산 (`/project-budgets`). 현장별 지급 현황에서도 연결한다.

## 입력 및 비교

- 자재비·인건비·기타비의 공사 전체 기간 지급예산을 입력한다. 회사의 3~6개월 자금계획과 별개다.
- 은행에서 지급할 금액 기준으로 작성한다. 자재비의 부가세와 급여 공제 차이를 고려해 지급액과 같은 기준을 사용해야 한다.
- 현장 배분된 누적 출금과 비교하며, 입금·회사 계좌 간 이체·본사 공통 지급·미배분 출금은 현장 지급 합계에 포함하지 않는다.
- 항목별 차액 = 지급예산 − 누적 배분 지급액. 지급률은 소수점 첫째 자리까지 버림 표시한다. 예산 미등록 및 0원 예산은 지급률을 계산하지 않는다.
- 빈칸은 미등록, 0원은 예산 없음이다. 일부 항목이 미등록이면 입력분 합계를 표시하되 전체 차액은 계산 대기로 남긴다.
- 항목별 초과 여부를 표시한다. 전체 차액이 양수여도 특정 항목을 초과하면 경고한다.
- 차액은 통장 잔액, 미지급 채무, 앞으로 지급할 금액이나 이익이 아니다. 미배분 출금이 있으면 실제 현장 지급액이 과소 표시될 수 있다.
- 현장 검색은 현장 코드·이름으로 검색한다. 기간 선택 없이 공사 전체 누적으로 비교한다.

## 변경 관리

- 등록·수정·해제 시 사유를 입력한다. 세 항목을 모두 비워 저장하면 미등록으로 복원한다.
- 별도 예산 버전으로 동시 수정을 확인한다. 회사 현장만 저장할 수 있다.
- 동일 요청 재전송은 중복 이력을 만들지 않는다. 변경 전후 값과 사유를 한 DB 트랜잭션에 저장한다.
- 최근 이력 10건에서 변경 전후 값을 펼쳐 확인할 수 있다.
- 예산 저장은 계약 공급가액, 은행 거래, 기존 현장 배분, 회사 자금계획을 변경하지 않는다.
- 실제 사용자 현장의 예산을 임의로 입력하지 않았다.

## 검증

미등록과 0원 구분, 항목별 초과, 일부 예산 미입력 시 전체 차액 계산 보류, 20자리 금액 정밀도, 회사 범위, 중복 요청, 수정 충돌, 잘못된 금액·사유 누락 차단, 예산 해제와 원본 보존을 검증했다.
브라우저 시나리오는 합성 현장의 인건비 150원 지급에 예산 100원을 입력해 50원 초과를 확인하고, 예산을 200원으로 수정해 차액 50원과 변경 이력을 확인한다.
