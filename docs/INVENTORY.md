# 자재·재고

자재·재고 → 자재·재고 관리에서 품목 코드·자재명·단위와 회사 창고·현장 장소를 등록합니다. 이력이 있는 품목 단위와 장소의 종류·현장은 변경할 수 없습니다.

입고는 도착 장소, 현장 사용·출고는 출발 장소, 이동·반납은 서로 다른 두 장소를 지정합니다. 현장 직납은 현장 장소로 입고합니다. 기초재고는 실사 기준으로 별도 입력하며 과거 매입을 다시 발생시키지 않습니다.

수량·매입 단가는 소수 넷째 자리까지 정수 연산으로 보존합니다. 매입 입고에는 단가와 실제 증빙의 품목 공급가액이 필요합니다. 수량×단가와 금액이 다르면 반올림·조정 내역을 원본과 확인해야 합니다. 매입 문서 연결은 선택 사항이며 연결한 품목 공급가액 합계가 원본 공급가액을 넘지 못합니다. 연결된 매입의 거래처 변경·공급가액 축소·취소도 보호합니다.

같은 품목의 입출고 관리번호와 같은 요청을 중복 처리하지 않습니다. 품목별 버전으로 동시 출고를 보호합니다. 현재 잔액뿐 아니라 과거 날짜별로도 재고가 음수가 되는 출고·소급 입력·취소를 막습니다. 잘못된 기록은 원본을 보존해 취소한 후 새 관리번호로 다시 등록합니다.

현재 재고는 전체 이력으로 계산합니다. 출력 목록은 최근 500건이며 미리보기·인쇄·엑셀에 입력 양식은 포함하지 않습니다.

이 원장은 물량과 매입 단가·증빙 금액을 추적합니다. 재고 평가 방법(FIFO/평균 등)과 결산 장부가액을 임의로 정하지 않습니다. 이동·사용이 매입·은행 지급·원가를 다시 생성하지 않으며, 미연결 증빙과 현장 발생원가의 확인은 별도로 필요합니다. 실제 기초재고·반품·매입할인·손실·평가 방법은 원본과 회계사무소 기준을 대조해야 합니다.
