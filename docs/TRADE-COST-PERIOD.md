# 다른 달 부분 감액과 공사별 원가 조정

원 작성월에 여러 공사로 배부한 매입을 다음 달 음수 수정계산서로 부분 감액한다. 원 배부 행과 금액은 그대로 보존하고 수정 작성월의 현장별·본사 차액을 별도 기록한다.

엑셀 검토에서 다른 달 부분 감액(기지급이면 해당 기지급 메뉴)을 선택한다. 원 청구를 고르면 현재 유효 배부를 불러온다. 감액 후 현장/본사 부담액을 직접 확인하고 저장한다. 새로운 현장으로 옮길 때도 명시한 배부 합계와 부가세 검토에 따른 순원가가 일치해야 한다.

- 과거 마감월의 원 배부와 회계 전달본을 유지한다. 수정 작성월에 원가 차액 표와 음수 계산서가 연결되며 중복 합산하지 않는다.
- 현재 공사 손익과 미지급 배부는 조정 후 가중치를 한 번만 사용한다. 새 현장 배부도 반영하며 조정에서 제외한 현장의 원가를 중복 유지하지 않는다.
- 총원가 화면에서 원 작성월 총액과 현재 유효 총액, 현장별 금액, 수정월 이력을 구분한다. 활성 기간 조정이 있으면 원 배부의 직접 수정/취소는 막는다.
- 정정은 최근 수정증빙부터 한다. 과거 조정 상세는 계속 볼 수 있으며, 후속 조정이 있으면 최근 증빙으로 안내한다. 정정은 해당 기간 차액만 되돌리고 원 배부를 변경하지 않는다.
- 원 지급·예산안·별도 초과 환급의 검증은 유지한다. 다른 달 전액취소 배부는 TRADE-COST-PERIOD-CANCELLATIONS.md를 따른다. 다른 달 차량 연결 정산은 아직 별도 개발 범위다.

마이그레이션 55는 TradeCostAdjustment와 현장별 부호 있는 차액 행을 추가한다. 각 조정의 전후 총액·공통액·현장 배부·원 증빙·이전 기준을 기록하며 금액·원본 소유·회사·순서를 서버에서 대조한다. DB 초기화 없음.

검증: 전체 단위/DB 220개, 기간/기존 배부 집중 19개, 관련 화면 5개, 타입/lint/운영 빌드, 55개 마이그레이션 격리 DB 백업·복구 통과. 모든 검사 자료는 합성 자료이며 실제 회사 자료·송금·기관 신고·회사 PC/NAS 운영 검증은 별개다.
