# 원본 엑셀 양식 유지 원칙

사용자는 화면이 바뀌면 업무가 피곤해진다고 설명했으며 ERP를 되도록 원본 엑셀과 동일하게 요청했다. 익숙한 양식 유지가 화면 개편의 우선 기준이다. 새 화면을 임의로 단순화하거나 기존 ERP 목록만을 원본과 동일하다고 표현하지 않는다.

## 확인한 원본

- 2026년.xlsx: 매 출, 매 입 및 월별 출/입 시트. 작성일자·승인번호·발급일자·전송일자·공급자/공급받는자 정보·합계금액·공급가액·세액·세금계산서 분류·품목·수금/결재일·비고·결재예정일 순서. 매입에는 결재계좌·거래명세서 등이 추가된다.
- 어음대장(2026).xlsx: 발행어음조회(발행일), 발행어음조회(만기일), 전북·신한·하나·국민·기업 시트. 조회 양식과 은행별 양식은 서로 다르므로 하나의 임의 표로 통합하지 않는다.
- 은행별 어음대장: 순·날짜·종류·번호·상호명·발행일·만기일·발행은행·금액·할인수수료·할인신청금액 배치를 확인했다. 발행 조회 양식에는 전자어음번호·전자어음금액·어음상태·발행일·만기일·수취인 정보·당행어음번호가 있다.

## 구현 기준

1. 제목·열 순서·항목명·병합된 머리글·색상·열 너비·합계 위치를 원본 기준으로 구현한다. 표시 열과 실제 데이터 모델 매핑은 별도로 확인한다.
2. 매입/매출, 발행 조회/은행별 어음 시트 구분을 화면 탭에 반영한다. 은행별 시트가 수취·배서·할인 중 어느 업무인지 내용 확인 없이 추정하지 않는다.
3. 저장·미리보기·프린트·엑셀 저장과 ERP 검토 상태는 표 바깥에 배치해 원본 열 순서를 바꾸지 않는다.
4. 원본에 있는 발급일자·전송일자·사업자정보 등 현재 ERP에 없는 필드는 저장 근거 없이 작성일자나 타 필드 값으로 채우지 않는다. 원본 보존·필드 추가·매핑 검토 후 반영한다.
5. 원본 양식 변경과 실제 회사 데이터 가져오기는 구분한다. 원본 실자료를 공개 저장소나 테스트 데이터에 넣지 않는다.

## 구현한 1차 화면

`/excel-ledgers`에 매 출·매 입·발행어음조회(발행일) 탭을 추가했다. 원본에서 머리글 텍스트·순서·색상·열 너비와 병합 범위를 추출한 비식별 레이아웃만 코드에 보관했다. 회사 원본 거래행은 저장소에 포함하지 않는다. 원본의 병합 머리글은 하나의 표시 열로 넓이를 합산한다.

현재 ERP 등록 자료를 표시하며 회사별 인증, 취소 매입·매출 제외, 페이지 50건 제한을 유지한다. 합계·미리보기·엑셀 저장은 현재 페이지 기준임을 표시한다. 날짜 셀을 누르면 기존 상세·수정 화면으로 이동하며 발행어음은 번호 셀을 사용한다.

실제 저장되지 않은 발급·전송일·사업자 상세·품목 명세는 빈칸이다. 작성일에는 현재 ERP 증빙일을 표시하므로 원본 작성일·발급일의 개별 보존은 추가 이관 작업이 필요하다. 수금·결재일은 은행 전액 연결인 경우 실제 연결일 목록이며 일부 연결은 비고에 표시한다. 은행별 어음 양식과 만기일별 탭, 원본 파일 이관·세부 필드 저장·일치 검증은 아직 남아 있다. 이 1차 화면을 원본 완전 재현/원본 이관 완료로 표현하지 않는다.
