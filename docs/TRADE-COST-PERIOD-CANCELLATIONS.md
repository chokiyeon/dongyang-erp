# 다른 달 전액취소와 공사 배부 원가

이미 마감한 원 작성월의 배부를 삭제하거나 0원으로 덮어쓰지 않는다. 다른 달 전액취소의 작성월에 현재 유효 원가의 반대 차액을 기록해 현재 공사 원가를 0원으로 정산한다.

엑셀 검토에서 다른 달 미정산 또는 기지급 전액취소를 선택한다. 원 청구와 현재 현장/본사 배부를 대조하고 원가 취소를 별도로 확인한다. 미지급 취소는 원 지급 예정을 보존해 남은 예정만 종료하며 가짜 환급을 만들지 않는다. 기지급 취소는 원 은행 기록을 유지하고 실제 지급액만 환급 대상으로 둔다.

부분 감액 뒤 잔액을 취소하면 남은 원가만 차감한다. 선행 감액 환급과 잔액 취소 환급을 다시 합산하지 않는다. 공제/불공제 매입세액을 반영한 총원가를 사용한다. 실제 자재 반품·정기 지급·차량 연결 등의 별도 보호를 우회하지 않는다. 다른 달 차량 연결은 TRADE-VEHICLE-PERIOD.md의 원본 보존 정산을 사용한다.

정정 화면에서는 현재 유효 원가와 복원할 이전 배부를 비교한다. 최근 증빙부터 정정하며, 후속 취소가 있으면 이전 감액 상세에서 해당 취소로 안내한다. 해당 수정월 차액만 정정하고 원 작성월 배부는 유지한다. 이미 환급한 은행 실적은 기존 규칙에 따라 먼저 확인해야 한다.

원 작성월 및 선행 감액월 회계 전달본을 유지하며 취소월에는 별도 원가 차액 표를 제공한다. 총원가 화면은 원 작성월 총액과 현재 유효액(전액취소 시 0원)을 구분한다. 새 DB 스키마 없이 기존 55번째 기간 조정 테이블의 취소 관계를 사용한다.

검증: 전체 단위/DB 224개, 집중 회귀 32개 및 추가 후속월/불공제 사례를 포함한 기간 검사 12개, 관련 화면 8개, 타입/lint/운영 빌드 통과. 회사 실자료·실제 송금·기관 신고·회사 PC/NAS 운영은 실행하지 않았다.
