# 사무실 현금 시제

자금 관리 → 사무실 현금 시제에서 실제 보관하는 현금을 관리한다. 최초 보관액은 기초 현금으로 한 번 입력한다. 0원으로 시작하면 기초액 없이 현금 보충·수입부터 등록한다.

통장에서 인출한 돈은 현금 보충, 다시 통장에 넣은 돈은 현금 반납이다. 현금 보충·반납은 수익이나 비용이 아니다. 통장 장부의 실제 인출·입금은 그대로 두고 증빙·관련 통장 칸에 연결 근거를 적는다. 이 기능이 은행 실적·세금계산서·공사 원가를 자동 생성하거나 변경하지 않는다.

현금으로 지출한 날짜·내역·금액·영수증 근거를 기록한다. 현장 지출·수입은 관련 공사를 선택할 수 있으며 당시 공사 코드와 이름을 보존한다. 원가는 기존 매입 또는 총원가 장부에서 근거를 대조하며 통장 인출과 현금 지출을 이중 원가로 반영하지 않는다.

입금·출금·잔액을 월별로 조회하고 전월 잔액을 이월한다. 과거일을 추가하거나 입금을 취소하면 이후 날짜의 현금 부족 여부도 검사한다. 같은 날에는 등록 순서를 유지한다. 잘못 등록한 행은 사유를 남겨 취소한 뒤 다시 등록하며 원본을 삭제하지 않는다. 마감월은 등록·취소·실사 변경이 차단된다.

조회월 말 보관액(당월은 현재액)을 실제 현금 또는 당시 실사 원본으로 확인해 입력하면 장부 잔액과 차이를 기록한다. 차액은 자동 입출금으로 맞추지 않는다. 실사 후 같은 월 또는 이전 월 장부가 변경되면 장부 변경·재대조 필요로 표시하며 원래 실사 기록을 보존한다.

장부와 실사 내역은 화면 업무 도구에서 인쇄·엑셀 저장하며 회계 전달본에도 포함된다. 이후 월 현금 입출금은 이전 마감월의 전달본을 바꾸지 않는다. 이월액과 실사액은 실제 은행 잔액에 합산하지 않는다.

57번째 마이그레이션으로 현금 원본과 취소 정보를 추가했다. 기존 DB 초기화 없음. 회사 실현금·통장·영수증 대조와 실제 Windows/NAS 운영은 별도로 검증해야 한다.
