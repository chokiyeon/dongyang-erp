# 같은 달 미정산 부분 감액

`매입·매출 → 매입매출 엑셀 검토`에서 음수 수정증빙의 `부분 감액 검토`를 선택한다. 원본 청구를 고르면 공급가액·세액·합계의 반영 후 금액을 표시한다. 실제 발행 원본과 잔액을 대조한 뒤 확인 체크·사유를 기록한다.

예: 공급가액 1,000원 + 세액 100원인 미정산 청구에서 공급가액 -200원·세액 -20원의 수정증빙을 연결하면 현재 청구는 공급가액 800원 + 세액 80원, 합계 880원이 된다. 기존 은행 금액·수금/지급 실적·자금예정을 생성하거나 변경하지 않는다. 공사의 계약금액도 자동 변경하지 않는다.

## 처리 조건

- 같은 회사·매입/매출 구분·사업자번호·작성월의 세금계산서 원본이며 서로 다른 승인번호여야 한다. 매입은 공급자, 매출은 공급받는 자 사업자번호를 대조한다. 활성 감액이 있으면 그때 보관한 원본 사업자번호를 후속 대조에도 사용해 거래처 마스터 변경으로 다른 사업자의 증빙을 연결하지 않도록 한다.
- 유효한 음수 증빙만 선택할 수 있다. 중복·충돌·날짜·금액 합계 오류는 먼저 확인한다. 서버는 실제 XLSX를 다시 읽고 화면 원본 해시도 대조한다.
- 원본은 미정산이며 은행 실적·예산안·정기 지급·자재 입고·차량 비용·활성 공사 배부 연결이 없어야 한다. 이미 지급한 청구의 환급을 이 기능으로 처리하지 않는다.
- 공급가액·세액을 각각 감액하고 남은 합계가 양수여야 한다. 전액/초과 감액이나 남은 세액이 공급가액보다 큰 조합은 거부한다.
- 마감된 기간은 변경할 수 없다. 요청 재시도·동시 요청·원본 버전·기존 승인번호를 검사한다.

## 원본·합계·대조

원본 파일·선택한 행·감액 전후 금액·사업자번호·승인번호·사유는 별도로 보관한다. 문서의 현재 금액은 감액을 반영한 순액이며 미수/미지급·공사 발생원가·같은 달의 세액 집계는 이 순액을 사용한다. 감액 증빙의 음수 금액을 다시 차감하지 않는다. 회계 전달본에는 감액 전후 금액과 원본 XLSX도 포함한다.

엑셀 원본의 열 배치는 유지한다. 문서 상세에 감액 반영 상태와 증빙 링크를 표시한다. 엑셀 양식 장부의 비고에는 감액 건수·발행 원본 합계·현재 청구 합계를 표시하며 표의 금액과 합계는 감액 후 현재 순액이다. 발행 원본 금액과 현재 순액을 구분해 원본 재업로드 대조에는 `발행 원본 일치·부분 감액 반영`으로 표시한다. 감액된 잔액을 발행 원본 금액으로 오인하거나 기존 이관을 덮어쓰지 않는다.

## 입력 오류 정정

`부분 감액 내역 → 감액 상세 → 입력 오류 정정`에서 사유를 기록하면 감액 전 금액으로 복원하고 정정 이력을 남긴다. 여러 번 감액했으면 최근 감액부터 역순으로 정정한다. 이후 지급·예산안·자재·차량·원가 연결 또는 마감이 있으면 단순 복원을 거부한다.

활성 감액이 있는 원본의 금액·거래처·공사·증빙일·승인번호·세무 구분을 일반 수정으로 바꾸거나 일반 취소로 없앨 수 없다. 이름·비고·기한 등의 정정은 기존 보호 규칙을 따른다. 원본 결재 표기의 지급 대조 확인은 금액 변경으로 다시 검토 대상이 된다.

현재 범위는 같은 달의 연결 없는 미정산 부분 감액이다. 다른 달의 감액, 이미 지급한 금액의 환급, 연결된 입고의 반품/손실은 별도 정산 개발 대상이다. 실제 세금계산서 발행·취소·세무 신고·은행 송금은 실행하지 않는다.
