# 공사별 손익계산서와 준공 예상 손익

## 화면

- 공사 관리 → 준공 예상 손익 (`/project-profit`): 공사별 원가·전망 관리와 적자 예상 목록.
- 현장 관리 또는 위 목록의 ‘손익계산서’: `/project-profit/statement?project=현장ID`에서 한 공사만 조회한다.
- 손익계산서에서는 해당 공사의 기본정보·계약 공급가액·발생 원가·남은 예상 원가·예상 이익/손실·이익률·근거 자료를 확인한다.
- 공통 미리보기·프린트·엑셀 저장은 해당 공사만 포함한다. 작성 기준과 검토 상태도 표에 포함하여 출력한다.

## 계산 기준

공사 전체 확정 계약 공급가액 − 이미 발생한 원가 − 남은 예상 원가 = 준공 예상 이익/손실.

이는 계약 대비 준공 전망이다. 진행률에 따른 당기 수익 인식, 결산 손익, 법인세 계산 결과가 아니다. 공사대금 수금과 이익은 다른 개념이다.

### 발생 원가

1. 해당 현장의 취소되지 않은 매입 문서 공급가액을 반영한다. 매입의 원가 구분(자재비·인건비·현장 기타비·배부 공통경비)은 거래 자료에서 직접 선택한다.
2. 불공제로 확인한 부가세는 원가에 포함하고 공제 가능 확인 세액은 제외한다. 세액이 있는 매입에서 공제 검토가 보류이면 이익 계산을 보류한다.
3. 매입 문서에 없는 발생 급여·미청구 자재·경비·배부 공통경비는 ‘추가 발생원가’로 등록한다. 미지급액도 포함한다.
4. 이미 등록한 매입·인건비를 추가 원가에 다시 입력하지 않는다. 후에 매입 문서를 등록한 경우 기존 추가 원가가 중복인지 확인해 취소한다. 의미가 같은 두 자료를 자동 식별하는 기능은 없다.
5. 은행 지급 배분·미지급 잔액을 다시 발생 원가에 더하지 않는다. 매입 미지급 잔액은 부가세 포함 현금 채무이며 손익과 별도로 표시한다.

### 남은 예상 원가와 수입

- 남은 자재비·인건비·현장 기타비·배부 공통경비를 모두 입력한다. 빈칸은 미확인, 0원은 해당 비용이 더 발생하지 않을 전망이다.
- 미래 비용은 발생원가에 기록하지 않고 남은 예상 원가로 기록한다.
- 미승인 추가공사 금액은 별도 기록하되 이익에 더하지 않는다. 승인된 계약 변경은 현장 관리의 계약 공급가액에 반영한다.
- 기존 지급예산은 부가세 포함 등 지급 기준이므로 손익 원가로 자동 복사하지 않는다.

## 검토와 변경 보호

계약금액, 매입 원가 구분·증빙 원본·공제 여부, 남은 원가 네 항목을 확인하고 발생원가의 중복·누락 여부를 확인해야 예상 이익을 표시한다. 입력 중인 전망은 미확인 초안으로 저장할 수 있다.

검토 시 계약금액과 원가 자료의 내용으로 기준 지문을 저장한다. 계약금액·매입 원가 구분/금액/공제 검토·유효 추가 원가가 바뀌면 재검토 전 이익을 표시하지 않는다. 은행 연결로 매입 지급액만 변한 경우는 발생원가가 같으므로 이익을 다시 차감하지 않는다.

발생원가 등록·수정·취소와 전망 수정에는 회사 범위·별도 원가 버전·요청 중복 방지·사유·전후 이력을 적용한다. 원가 취소는 이력을 보관하며 은행·매입·기존 계약금액을 변경하지 않는다.

현장 미지정 매입, 누락 급여·경비, 누락된 추가공사 계약은 자동으로 추측하거나 현장에 배분하지 않는다. 발생원가의 완전성은 현장 담당자 자료와 대조해야 한다. 이익 보장 또는 자동 견적 결정 기능은 아니다.
