# 월말 경리 마감 점검

업무 현황 → 월말 경리 마감 점검에서 대상월을 선택한다. 원본을 수정하지 않고 회사별 자료를 같은 조회 시점 기준으로 읽는다.

| 점검 | 범위 |
|---|---|
| 은행 회계코드 | 해당 월 은행 거래, 내부이체 제외 |
| 증빙 원본·부가세 | 해당 월 증빙일, 취소 제외, 세액 있는 매입의 공제 검토 |
| 현장·본사 구분 | 해당 월 증빙에 현장도 본사·공통 표시도 없는 경우 |
| 정기 지급 | 대상월에 유효한 정기 지급의 월별 내역 생성·금액·확인 여부 |
| 급여 지급 확인 | 대상월 재직 상용직 및 등록된 출역이 있는 일용직, 취소 지급 확인 제외 |
| 총원가 배부 | 해당 월 발생일의 사용 중 원가 검토 가운데 재검토 표시 |
| 미정산 예정 | 전월 이월을 포함해 대상월 말일까지 남은 예정, 완료·최종 정산 및 취소 실적 구분 |

건수는 서로 중복될 수 있으므로 합산 거래 건수나 부족 금액으로 표시하지 않는다. 0건은 등록된 자료 안에서 해당 조건이 없다는 뜻이며 원본 완전성·법적 결산 완료를 뜻하지 않는다. 해당 월 출역이 아예 등록되지 않은 일용직, 원가 확인 자체가 없는 원본, 은행 잔액·세무 신고자료 등은 별도 대조한다.

프린트·미리보기·엑셀 저장은 공통 표 내보내기를 이용한다. 최근 전달본 차수와 상태를 표시하고 같은 대상월의 회계 전달·인수인계 화면으로 이동한다. 이 화면에서 회계 기간을 잠그거나 마감 완료를 자동 처리하지 않는다. 기존 전달본과 현재 원본의 차이는 전달 화면에서 확인한다.
