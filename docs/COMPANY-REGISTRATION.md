# 사업자등록증 회사 정보

기준정보 → 회사 정보에서 법인명/상호, 공동대표, 사업자등록번호, 법인등록번호, 종사업장번호, 사업자 구분, 개업연월일, 등록증 발급일, 사업장 소재지, 본점 소재지, 업태, 종목, 관할 세무서와 전화/팩스/이메일을 입력한다. 해당 없는 항목은 비워 둘 수 있다.

사업자등록번호는 10자리, 법인등록번호는 13자리, 종사업장번호는 해당 시 4자리를 보관한다. 앞자리 0을 유지하며 하이픈·전각 숫자를 정규화한다. 날짜·이메일 등 입력 형식만 검사하며 실제 등록 사실·세무 상태를 조회/확정하지 않는다. 공동대표는 한 줄에 한 분씩 입력한다.

입력 항목을 명시적으로 비우면 해당 내용을 지우고, 예전 화면처럼 새 항목을 보내지 않은 요청은 기존 내용을 유지한다. 수정 버전·중복 요청을 확인하고 회사 정보 변경 이력을 보관한다. 회사명·대표자의 기존 값과 사업자 정보는 추가 마이그레이션만으로 보존한다. 등록 정보 저장만으로 거래처·급여·세무 자료를 일괄 변경하거나 신고하지 않는다.
