# 원본 어음대장 양식과 은행 분류

원본 `어음대장(2026).xlsx`의 발행일별·만기일별 조회와 전북·신한·하나·국민·기업 탭의 머리글, 순서, 색상, 열 너비를 `/excel-ledgers`에 반영한다. 레이아웃만 저장소에 보관하며 실제 회사 거래행은 포함하지 않는다.

은행별 탭은 수취어음의 **확인한 대장 은행**으로 분류한다. 발행은행이나 할인 입금 계좌를 보고 자동 분류하지 않는다. 기존 값은 모두 비어 있으므로 ‘은행 미분류’에서 확인할 수 있다. 원본 확인 전 실제 파일의 각 행을 수취어음으로 자동 이관하지 않는다.

## 표시 기준

- 날짜: ERP의 수취일. 원본 작성 날짜와의 일치는 자료 이관 시 따로 확인한다.
- 종류·발행일·발행은행: 원본 확인 후 직접 입력한 값만 표시한다. 발행일은 수취일 이후일 수 없다.
- 번호·상호명·금액·만기일: 등록한 수취어음의 관리번호·지급 거래처·액면·만기일이다. 번호가 원본 전자어음번호와 같은지는 이관 때 확인한다.
- 할인수수료: 실제 할인 처리에 저장한 수수료이다. 미처리는 빈칸, 실제 0원은 0이다.
- 할인신청금액: 현재 별도 저장하지 않으므로 빈칸이다. 실입금액이나 액면금액으로 대신 채우지 않는다.
- 순: 현재 조회에서의 순번이다. 원본 순번 이관 완료를 의미하지 않는다.
- 취소 수취어음: 은행별 대장과 합계에서 제외한다. 발행어음 조회는 기존 상태 표시를 유지한다.

## 원본 정보 정정

수취어음 상세에서 대장 은행·원본 발행일·발행은행·종류만 사유와 함께 정정할 수 있다. 같은 요청 재시도는 한 번만 반영하며 다른 내용 재사용, 오래된 버전, 취소 어음, 마감된 수취월의 수정은 차단한다. 실제 지급·액면·상태·자금계획은 바꾸지 않는다. 변경 전후는 어음 변경 이력에 남긴다. 회계 전달본에도 원본 메타데이터를 포함해 전달 이후의 차이를 확인한다.

## 사용 범위

은행별 대장·발행 조회 모두 현재 페이지 최대 50건과 그 페이지 합계를 출력한다. 발행일별은 발행일 역순, 만기일별은 가까운 만기일 순이다. 원본 전체 파일의 자동 이관과 모든 날짜·번호 의미의 대조, 회사 PC/NAS 실행은 아직 완료하지 않았다.
