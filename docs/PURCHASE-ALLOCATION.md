# 한 매입 계산서를 여러 공사에 배부

1. 매입 원본을 한 번 등록한다. 공급가액·부가세·원가 구분과 공제 여부, 원본을 확인한다.
2. 여러 공사로 나눌 매입은 단일 현장을 비워 둔다. 단일 현장이 지정된 매입은 그 공사의 원가로 이미 반영되므로 동시에 배부할 수 없다.
3. 매입 목록의 ‘여러 공사 원가 배부’ 또는 ‘총원가 확인·공사 배부 → 여러 공사 매입 원가’를 연다.
4. 확인된 원가를 공사별 금액과 본사 공통액으로 나눈다. 합계는 매입 원가와 같아야 한다. 공제 부가세는 제외하고 불공제로 확인한 부가세만 포함한다. 발생일은 매입 발행일이다.
5. 같은 비용을 다른 매입·수기 원가에 중복 반영하지 않았는지 확인하고 사유를 기록한다.

배부는 매입 금액·은행 지급·재고 수량을 바꾸지 않는다. 각 공사 손익계산서에 해당 배부 원가가 반영된다. 미지급 참고액은 청구의 전체 미지급액을 원가 비율로 안분한다. 원 단위 잔액은 마지막 배부 대상으로 반영한다. 특정 공사부터 지급했는지를 확정하는 자료는 아니다.

송금 준비표는 공사 필터를 사용해도 그 공사에 걸린 계산서의 전체 미지급액을 한 번 표시한다. 공사별 원가와 청구 전체 송금액을 구분한다. 지급 후 남은 미지급액은 자동으로 다시 대조한다.

원본 금액·부가세·공사 구분 등 원가 기준을 정정하면 기존 배부와 손익을 재검토 상태로 둔다. 배부를 다시 확인하기 전에는 해당 송금표도 보류한다. 매입 취소 또는 단일 현장으로 변경하려면 기존 배부부터 취소한다. 배부 취소는 원래 매입이나 은행 지급을 삭제하지 않는다.
