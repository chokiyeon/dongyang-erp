# 다른 달 작성 수정계산서의 전액취소·환급

2026-11-04. 원본 엑셀의 작성일자를 기준으로 기간을 구분하며 파일 이름·업로드일·전송일로 작성월을 바꾸지 않는다.

## 처리

- 매입매출 원본 검토에서 음수 행의 **다른 달 취소 검토** 또는 **다른 달 기지급 취소·환급 검토**를 선택한다.
- 이전 작성월의 원본과 사업자번호·구분·공급가액·세액·합계 전액을 대조한다. 원본 확인된 세금계산서만 처리한다.
- 미정산 원본은 남은 청구를 종료한다. 일부/전액 지급 원본은 원 지급을 보존하고 실제 지급액만 별도 환급 예정으로 만든다. 이후 환급 연결·잔액·예정일 변경은 기존 환급 기능에서 처리한다.
- 현재 미수·미지급과 누적 공사 원가는 취소 원본을 제외한다. 원본의 공급가액·세액·합계·원 작성일 및 은행 지급액은 보존한다.

## 기간 보존

원 작성월의 부가세와 회계 전달본은 원본을 유지한다. 수정 작성월에는 음수 증빙을 한 번 반영한다. 예를 들어 9월 공급가액 1,000원/세액 100원 원본을 10월 전액 취소하면 9월은 +1,000/+100, 10월은 -1,000/-100이다. 두 기간을 합산하면 0이 된다. 같은 달 취소의 원본 제외 방식과 혼합해 이중 차감하지 않는다.

마감된 원본 작성월을 재개방하지 않아도 이후의 열려 있는 수정월에서 처리할 수 있다. 입력 오류 정정은 수정월을 보호하며 이전 월 원본의 금융·세무 금액을 변경하지 않는다. 이후 환급이 앞선 월 전달본을 바꾸지 않는지도 검증했다. 회계 전달본의 수정증빙 참고표를 주 매입매출 표에 다시 합산하지 않는다.

엑셀 양식 장부는 원래 열/머리글 배치를 유지하면서 원본과 다른 달 음수 증빙을 각각 표시한다. 같은 달 부분 감액은 기존 방식대로 원본의 해당 월 금액에 반영된다. 재발급과 다른 달 정산의 자동 승계는 별도 검토 범위로 차단한다.

## 제한과 검증

선행 감액의 전후 금액과 순서가 검증되면 남은 청구 전액취소를 처리한다. 연결 자재/차량/원가 배부 원본의 추가 반품 정산은 후속 개발 범위다. 세금계산서 발행·국세청 신고·실제 이체를 실행하지 않는다. 세액 화면은 등록한 작성일과 증빙에 따른 추정/대조이며 실제 신고 판단을 대체하지 않는다.

새 마이그레이션 없이 기존 취소 이력의 REGISTER_LATER 작업을 기간 구분 기준으로 사용한다. 원본 월 유지/수정월 반영, 마감, 사업자, 구분, 전액/부분 구분, 기지급 원 지급 보호, 동시에 같은 요청 처리, 입력 정정, 부가세, 회계 ZIP, 엑셀 원본 배치를 검증했다. 전체 단위/DB 142개 통과(`/tmp/later-full-tests.log`). 같은 달/다른 달 및 일부/전액 지급의 화면 5개 흐름 통과(`/tmp/later-browser.log`), 미정산 같은 달/다른 달 화면 2개 통과(`/tmp/later-unpaid-browser.log`). 타입·lint·운영 빌드 통과.
