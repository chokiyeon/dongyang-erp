# 보유 차량·현장 사용·과태료

차량 관리 → 차량·과태료 관리에서 차량 번호·차종·담당자·운용 방식과 보험 만료일·검사 기한을 등록합니다. 트럭·승용차를 구분하며 실제 회사 차량을 자동 생성하지 않습니다.

## 사용 이력

고정 현장, 여러 현장 공용, 본사 업무 운용을 구분합니다. 시작일·종료일·현장 또는 본사·운전자·사용 근거를 기록합니다. 고정·본사 차량은 사용 기간 중복을 막습니다. 종료일은 해당 날짜까지 사용한 것으로 보므로 다음 배정은 다음 날부터 등록합니다. 공용 차량은 같은 기간 여러 현장 이력을 허용합니다.

현재 사용 현장은 오늘이 사용 기간에 포함된 이력으로 표시합니다. 비용의 현장은 배정 이력만으로 자동 확정하지 않습니다. 공용 비용의 귀속을 모르면 미배분으로 남깁니다. 취소한 배정과 변경 사유는 보존합니다.

## 비용·위반 내역

유류비, 정비·수리, 보험료, 자동차세, 통행료, 주차비, 과태료, 범칙금·벌금과 기타 비용을 기록합니다. 관리번호, 실제 발생일, 금액, 증빙 메모가 필요합니다. 현장 또는 본사·공통은 확인한 경우에 지정합니다.

회사 부담·운전자 부담·확인 필요를 구분합니다. 과태료·범칙금은 운전자, 부과기관, 납부기한을 함께 확인합니다. 납부 상태는 납부 확인 필요·미납부·납부 확인이며, 납부 확인에는 발생일 이후의 실제 납부일이 필요합니다. 납부기한 미확인도 0이나 임의 날짜로 대체하지 않습니다.

미납부·납부 미확인 위반 목록은 조회월과 무관하게 모든 미처리 과태료·범칙금을 보여 줍니다. 월별 차량 비용은 실제 발생월 기준으로 조회하고 회사 부담액을 별도 합산합니다. 운전자 부담액을 회사 비용 합계에 섞지 않습니다. 미지정 현장을 임의로 배분하지 않습니다.

보험·검사 기한이 지난 차량과 앞으로 30일 안에 도래하는 사용 중 차량을 모아 보여 줍니다. 기한을 등록하지 않은 차량은 목록에 미등록으로 표시하며 임의 계산하지 않습니다.

## 정정·출력·범위

버전과 요청 식별자로 수정 충돌·재전송을 보호하고 전후 값과 사유를 보존합니다. 같은 차량 번호는 회사 내 중복 등록하지 않습니다. 비용 관리번호는 해당 차량 안에서 중복 등록하지 않습니다.

상단 미리보기·프린트·엑셀로 저장은 조회한 현황·미처리 위반·월별 비용·사용 이력을 출력합니다. 입력·조회 양식과 변경 사유 입력란은 제외합니다. 비용 금액은 엑셀 숫자로 내보내며 15자리 초과 금액은 문자열로 보존합니다.

납부 확인은 차량대장의 수기 관리 상태입니다. 은행 실제 거래를 생성하거나 장부·송금표·공사 손익·부가세에 자동 반영하지 않습니다. 비용을 회계 자료에 별도로 입력할 때 같은 지출을 중복 계상하지 않도록 원본 관리번호를 대조하세요. 과태료·범칙금 등의 회사 부담·손금 인정은 별도 세무 검토가 필요합니다.

이메일·카카오톡·고지서의 파일 첨부, 정비 주행거리·자동 알림 전송, 은행·매입 원본 연결 및 공용 비용 배부 자동화는 후속 범위입니다.
