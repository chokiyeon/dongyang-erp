# 세액 전망과 회계 전달본

## 법인세·지방소득세 추정

매입·매출 → 법인세·지방소득세 추정에서 월별 시점의 연간 예상 회계이익, 세무조정, 적용 가능한 이월결손금·공제감면·기납부액을 입력합니다. 사업연도에 맞게 검토한 과세표준 구간 3개 상한과 4개 구간별 법인세율·지방소득세율을 직접 입력합니다. 지방세를 법인세의 일정 비율로 자동 간주하지 않습니다.

법정 세율을 임의로 기본값으로 확정하지 않습니다. 원본 검토 근거와 확인 표시를 저장해야 합니다. 세무조정·결손금/공제 한도·최저한세·특별 과세 등 법적 요건은 검토된 입력을 전제로 합니다. 입력 기준과 계산 결과·변경 사유는 이력으로 보존합니다. 음수 잔액은 입력한 기납부액이 추정 세액보다 큰 상태이며 실제 환급 확정이 아닙니다. 계산이 실제 납부 일정이나 자금 출금을 생성하지 않습니다.

## 회계사무소 전달·인수인계

대상월의 은행 거래, 매입·매출, 실지급 급여, 차량 비용, 자재 입출고, 발행·수취어음, 법인세 전망과 확인 총원가 배부를 전달본으로 보관합니다. 거래금액·기준정보·당시 상태를 저장하며 기존 전달본을 덮어쓰지 않습니다. 미분류·원본 미확인·부가세 미검토·미연결 자재·별도 노무 신고 확인사항을 표시합니다.

같은 원본은 기존 차수를 사용하고 바뀐 원본은 새 차수를 만듭니다. 전달본 생성은 일관된 DB 스냅샷에서 수행합니다. 실제 전달을 마친 사용자가 전달 완료를 기록하고, 내용 검토 후 전달본 마감으로 변경합니다. 프로그램이 외부로 메일이나 메시지를 보내지 않습니다.

전달 후 원본이 바뀌면 변경을 표시하며, 오래된 원본으로 전달 완료·마감하는 것을 막습니다. 기존 전달본 엑셀은 생성 당시 값으로 내려받습니다. 새 전달본에서 변경된 자료를 확인하고 차수별 이력과 사유를 보관하세요. 전달본 마감은 원본 장부의 전역 수정 금지와 다르며 마감 후 변경도 표시합니다.

전달본 전용 엑셀은 안내 1시트와 자료 11시트로 구성됩니다. 원본 식별자·관리번호로 추적하며 계좌·회계코드 앞자리 0과 15자리를 넘는 금액을 문자열로 보존합니다. 관리자 인증 후에만 다운로드합니다. 급여 실지급액은 노무 신고용 금액·총 노무원가가 아니며, 은행·매입·급여·차량·재고에서 동일 지출을 중복 합산하지 않아야 합니다. 세무 신고 원본 파일·계산서·노무 신고 자료는 회계사무소와 별도 대조합니다.

귀속월별 원본 첨부 목록과 당시 첨부 파일을 전달본 ZIP으로 함께 내려받을 수 있습니다. [첨부·묶음 기준](EVIDENCE-ATTACHMENTS.md).
