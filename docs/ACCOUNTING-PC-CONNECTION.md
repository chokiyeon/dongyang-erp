# 경리 PC 접속 설정

ERP-Main-LAN.exe는 **ERP가 설치돼 현재 실행 중인 메인 PC**에서 실행한다. 경리 PC에는 실행하지 않는다.

1. 메인 PC에서 진행 중인 ERP 업무를 저장한다.
2. ERP-Main-LAN.exe를 실행하고 윈도우 관리자 권한 요청을 확인한다.
3. 실제 메인 PC의 주소가 192.168.0.12인 경우만 설정한다. 회사망이 공용 프로필이면 신뢰할 수 있는 사내 연결인지 확인하는 창에서 동의한 경우에만 개인 프로필로 전환한다.
4. 현재 서버 종료 여부에 동의하면 본 설치 폴더의 Node/Next 서버인지 대조한 후 종료하고 해당 주소/포트/Node 실행 파일에 한정한 개인·도메인/LocalSubnet 방화벽 규칙을 적용한다.
5. 완료 화면의 ERP 열기를 선택한다. 경리 PC에서 http://192.168.0.12:3000 에 접속하고 기존 ERP 비밀번호로 로그인한다.

Node.js/PostgreSQL은 메인 PC에서만 실행한다. 경리 PC에는 브라우저만 있으면 된다. Client.exe는 선택적으로 경리 PC의 바탕화면 연결 아이콘을 만든다. 대표님 PC 및 나머지 PC의 접속 배포는 별도 진행한다.

원래 .env.office는 메인 PC의 backups/lan-config/<고유값>/에 보존한다. DB/비밀번호/NAS 공유 권한/공유기 설정은 변경하지 않는다. 코드의 PowerShell 구문과 NSIS 빌드는 검사했으나 실제 회사 PC의 주소·UAC·방화벽·사내망 연결 확인은 사용자 PC에서 필요하다.

## 매일 주소를 입력하지 않는 방법

ERP-Share-Client.exe를 NAS 쓰기 권한이 있는 PC에서 실행하면 \\192.168.0.250\work\동양계전ERP 에 동양계전ERP_경리PC연결.exe와 접속 안내를 저장한다. 이 작업은 NAS에 연결 프로그램을 배치하는 것으로 서버 접속 설정과 다르다.

경리 PC에서 공유폴더의 동양계전ERP_경리PC연결.exe를 처음 한 번 실행하면 바탕화면에 ERP와 NAS 공유폴더 바로가기를 만든다. 다음날부터 ERP 아이콘을 더블클릭한다. Node.js/DB를 추가 설치하지 않으며 NAS 자격증명은 Windows에서 직접 입력한다. 프로그램 배치 도구는 기존 같은 이름의 연결 프로그램을 ERP-연결도구백업에 보존 후 갱신한다.
